Hana-ComfyUI · 提交历史

你做的每一步，都留了痕

每提交一次，画布底下就多一格。那条横在底部的，叫提交历史框；能展开铺成一片的，叫提交树——它们是同一段历史的两种看法：一个按时间排开，一个按血脉分层。

提交历史框

按时间，从左到右
一格 = 一次提交 越靠右越新
← 较早 较晚 →

每格都是一次提交，越靠右越新。格子里的小彩条，就是这一次动过的画布功能区。

  • 单击看这一版长什么样（缩略图）
  • 双击回到这一版
  • 白圈当前选中的那格
  • 橙点最新一版

提交树

横轴是时间，纵轴是分支
从哪分出去、各自走了多远，一眼看清 回跳后再提交，就长出新枝
你 agent

横着看是时间，竖着看是分支。上排这条主线一路是你（蓝框）；中途从某个节点分下去的那条，是 agent 替你跑出来的（紫框）。分叉处那条线先拐一个小小的弯，再走直线到分出去的节点——跟画布里看到的一致。

怎么读

四样东西，决定一格的样子
  • 外框颜色 · 谁提交的 蓝＝你自己点的；紫＝agent 替你跑的。人和机器的笔迹，分开记。
  • 外框线型 · 做了什么 实线＝提交运行；虚线＝存档（只记下这一版，不跑）。
  • 内部彩条 · 动了哪些功能区 每个功能区有各自的颜色（就是画布里你给分组设的框色）：亮起＝这次动过它，灰＝没动。
  • 宽度 · 是否合并 画布没改就再跑一次，不新开格——并进上一格，用宽块表示。
