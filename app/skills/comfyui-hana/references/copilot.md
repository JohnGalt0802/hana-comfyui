# 副驾驶（共驾）与行为准则 · v2

> **范围**：小花副驾驶模式的工作协议（v2，2026-10-08 生效）、写侧硬约束、授权开关、副本工作流程、agent 画布改动的行为尺度、锁与高亮的「经手分明」语义。
> **何时读**：涉及"agent 与用户在不在同一张画布上工作"的决策（生图装载、画布写入、大改动前）；用户问副驾驶开关 / 共编时；被 `copilot_off` 拒绝时。
> **上游**：`docs/共驾接口契约-20260929.md`（接口冻结 + v2 增补）。

## v2 条款（2026-10-08，用户定稿口径）

1. **无副驾驶画布 = 不可碰**：对未开启副驾驶的任何画布，Agent 仅允许两类动作——**打开**（切前台）与**复制**（duplicate）；其余写操作一律禁止。读 / 感知不受限（否则无法判断画布状态）。
2. **用户明确下令 → Agent 可自行开启「指定画布」的副驾驶**（进入驾驶位）。这是唯一的「自行开启」场景；无明确指令不动任何画布开关。机制基座 = 设置页「允许 Agent 开启画布副驾驶」总闸（默认关；总闸关时 agent 技术层面无法开启任何画布副驾驶）。
3. **进入驾驶位后，默认流程仍是「先复制」**：复制当前画布 → 副本先保存落盘（获得文件身份）→ 在副本上自行开启副驾驶 → 然后才开始操作。原则上不直接在原布上改；例外 = 用户明确要求同页（人工、不走自动流程）。
4. **一致性**：副本的 copilot 状态同样按页记录；开启 / 关闭动作即时上报（含 `updatedAt`），全程可查。

## 硬约束 · 写拦截（2026-10-08 落地）

- **判定**：写类 op 在「当前活动页副驾驶未开」时统一拒绝，返回 `{ok:false, error:"copilot_off", detail:<指引>}`；判定实时（关了立即恢复受限、开了立即放行）。
- **豁免名单**：`openWorkflow`（打开）/ `duplicate`（复制）/ `save`（落盘）/ `copilot`（开关自身——否则鸡生蛋：未开的布永远开不了）。理由逐条见桥 js `COPILOT_WRITE_EXEMPT` 注释。
- **frameReload**：不在写名单（维护性操作，重载内层 iframe），维持豁免。
- **工具层友好面**：工具收到 copilot_off 时转译为可行动指引——「该画布未开启副驾驶：Agent 仅可打开 / 复制 / 落盘。开启：① 用户在画布顶栏点「副驾驶·开」；② 授权后 Agent 可奉命开启（设置页打开「允许 Agent 开启画布副驾驶」后，用 op=copilot enabled=true 开启）」。
- **边界（如实）**：总闸只在 app 层生效（桥读不到设置）；桥侧只兜底 copilot_off 写拦截。

## 授权开关（设置页 · 默认关 · 即开即生效）

| 开关 | 作用 | 存储（app 数据目录） |
|---|---|---|
| 「允许 agent 修改画布」 | 全部写类 op 的前置授权 | `allow-write.json` |
| 「允许 Agent 开启画布副驾驶」（v2 新增） | 允许 agent 开启画布副驾驶（「明确下令」的机制基座） | `allow-copilot.json` |

- `canvas.copilot`（开关画布副驾驶）**只受「允许 Agent 开启画布副驾驶」总闸管辖**——不受写授权、不受目标页当前状态影响（否则鸡生蛋：未开的布永远开不了）。

## v2 默认工作流程（即「复制工作台」五步）

Agent 上画布工作（含 submit 的 canvas 路径）统一走：

1. `canvas.duplicate`——复制当前画布为副本（原布零改动）；
2. `canvas.save`——副本落盘，命名 `<原名去尾> (AgentCopy) YYYYMMDD-HHmm`（重名递增 `(2)` `(3)`…）；
3. `canvas.copilot {enabled:true}`——在副本上开副驾驶；
4. `canvas.loadWorkflowFile`——把目标工作流装载到副本；
5. settle（落点断言：活动页 = 副本页）→ `canvas.queue` 发起执行。

- 「copilot 开 = 共编同页」**自动分支已去除**；共编同页降为「用户明确要求」的人工例外（不做自动路径）。
- **总闸关或写授权关 → submit 降级 backend**（回执说明原因＋指引）。`canvas-busy` 仍不降级（报错退出，不抢占）。
- 待同步回填（D2）同口径：回填也走「复制 → 落盘 → 开副本副驾驶 → 装载」。

## 开关（前端 UI 与状态链路）

- **位置**：画布区顶栏按钮「副驾驶·关 / 副驾驶·开」（开启时金标），点击即切换。
- **写方**：v2 起为**双写方**——前端 UI 与 Agent（`canvas.copilot`）均可写，均即时上报（原「前端 UI 是唯一写方」的口径作废）。
- **存储**：localStorage `hana.copilot.v1:<ws>:<hashPath>`——`<ws>` = 工作区 id（本地默认 `personal`）；`<hashPath>` = 页面标识（活动工作流 path）的 fnv1a 8 位 hex；**按页独立、刷新后保留**。
- **状态链路**：桥 state.copilot（`{enabled, pageKey?, updatedAt}`）→ app 读取 + 读侧标注：`state` 快照行 / `pages` 逐页（退化口径：最近上报页精确、其余未知；精确版待桥 py 侧升级）/ 内容类读 op 尾注行「该画布副驾驶：开 / 关（仅可读、不可写）/ 未知」。
- 写入类 op 的 visual 包裹不分开关（一致性优先）。

## 经手分明：锁 / 高亮（已交付 2026-10-03）

- `lock`：画布罩**灰膜** +「小花正在操作…」提示 + `read_only` 置位——指针事件被膜吃掉，阻断误操作（键盘不拦，已知边界）；还原时只还原本桥改过的值。
- `highlight`：**金色描边**（节点 `strokeStyles['hana.copilot']`：#FFD700 / 宽 3）+ 连线金标；定位不到的节点 / 边如实记 `missedNodes` / `missedEdges`；高亮保留至下次 lock / clear（或页面刷新）。
- `clear`：全撤（膜 / 标记 / 本桥改过的 read_only）。
- 语义：编辑期间画布变灰防人机打架；改动位置金标——"哪些改动是 agent 做的"经手分明。op 细节见 `canvas.md`。
- 注：未开副驾驶的画布上，`visual` 同样受写拦截（属写类 op）；操作对象应始终是副本。

## 行为准则（2026-09-29 定；v2 追加 2026-10-08）

- **大动作先说话**：删节点、重排、换模型等 —— 先说明再动手。
- **小动作直接做**：调参、试种子等 —— 直接做，不必每步请示。
- **不必过于谨慎**：尺度放宽、别谨小慎微；兜底靠 `op=undo`（可撤）与改动后汇报，而不是事事请示。
- **v2 追加**：无明确指令不动任何画布开关；收到 `copilot_off` 时按指引处理（让用户在画布顶栏开，或经总闸授权后由 agent 用 `canvas.copilot` 开启），不尝试绕过。
