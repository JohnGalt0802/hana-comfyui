## 一、需求（John 定）

1. **提交树样式**：改成「昨天那张卡」（`OH-Works/Cards/canvas-history-compare` 的 `renderTimeline`）那种——**每个提交一根竖刻度，刻度上纵向堆叠若干小色条**，每根小色条代表一个框；该提交碰过的框亮，没碰的灰。
2. **弹层跟随画布**：提交历史框要像**画布里的模块**一样——**跟画布内容同步缩放平移**（画布放大它就放大，缩小它就缩小，拖画布它跟着走），不再"一拖就停在原地"。

## 二、P7-2 树样式（改渲染 + CSS）

### 2.1 每个节点的形态（参考卡 `renderTimeline`）
```
     ▁        ← 小色条 × N（N = 全局框数），每根 = 一个框
     ▁        ← 命中：亮色（按 source 四色）；未命中：灰
     ▁
     │        ← stem：竖线，表 kind（run 实心线 / save 空心或虚线）
```
- 现状是「9px 小柱 + 顶部一条横色条」→ 改为「**竖排小色条堆 + stem**」
- 色条数 = **全局框列表长度**；命中判定用 `blockNames.includes(框名)`
- 色条亮色取该提交的 `source` 色（user 冷色 / agent 暖紫）；`blockNames === null`（旧数据）→ 全部色条灰 + legacy 标记
- stem 颜色/形态表 `kind`（run 实线 / save 虚线或空心）

### 2.2 全局框列表（从哪来）
- **从 entries 收集**：遍历所有 entry 的 `blocks`，取 `name` 做并集（按首次出现序）
- 兼容旧数据（`blocks` 只有 `{name, nodeCount}`）→ 也取 `name`
- 空 → 退化为「单根色条」（不报错）

### 2.3 布局调整
- 行高加大（原来 20px，堆叠 N 根条需要更高）；面板高度按行数自适应，仍可滚动
- 保留：拓扑分层、SVG 连线、HEAD 高亮、气泡、点选回跳、收纳条计数

## 三、P6-2 弹层跟随画布（改定位机制）

### 3.1 机制
- 弹层仍为 DOM（`position: fixed`），但新增 **rAF 循环**（**只在弹层打开时跑，关闭即停**）：
  - 每帧读 `app.canvas.ds.scale` / `ds.offset`
  - 与上一帧比，**变了才更新**（避免无谓重排）
  - 更新内容：① 锚点位置（框顶部中心，`historyGroupTopScreen` 重算）② `transform: scale(k)`
- **缩放**：`k = clamp(ds.scale, MIN_SCALE, MAX_SCALE)`（默认 MIN=0.55、MAX=1.6，常量可调）
  - `transform-origin` = 弹层**底边中心**（对准框顶）
  - `transform: translate(-50%, -100%) scale(k)`，`left/top` = 锚点屏幕坐标
  - 效果：弹层底边中心始终钉在框顶上方，整体随画布缩放
- **下限保护**：`k` 不低于 MIN_SCALE，保证 zoom out 时文字仍可读

### 3.2 清理
- `historyBarClose` 里 `cancelAnimationFrame` + 清 rAF id（防泄漏）
- 弹层重开（切换框）→ 旧循环先停，起新的

### 3.3 不做
- 不改弹层的 DOM 结构/交互（气泡、缩略图、确认框全保留）
- 树（P7）**本批不跟随**（用户未要求；树贴底横条固定即可）

## 五、验收

| 项 | 判据 |
|---|---|
| 树样式 | 每节点竖排色条堆（框数根），命中亮/未命中灰，stem 表 kind |
| 树布局 | 分层/连线/HEAD 高亮/点选回跳 不回归 |
| 弹层跟随 | 缩放画布 → 弹层跟着放大缩小（带下限）；拖画布 → 弹层跟着框走 |
| 弹层不回归 | 气泡/缩略图/确认框/存档 全正常 |
| 关闭无泄漏 | 关弹层后 rAF 停（无持续重绘） |

**验证纪律**：真机 + 自建测试件；缩放/拖动用 CDP 或手测。
