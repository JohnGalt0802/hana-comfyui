# 诊断：差分放大产物"马赛克/糊"（2026-10-13 晚）

**症状**：`canvas op=on` 跑差分放大，产物 `qwen21_quality20_02952_.png`（1600×4800）"像马赛克"。

## 实测证据
| 指标 | 源图 02951（800×2400） | 产物 02952（1600×4800） |
|---|---|---|
| 清晰度 lapVar（原生尺度） | 152.7 | 84.9 |
| 清晰度 lapVar（缩回同尺度） | 152.7 | **38.3**（仅 1/4） |
| 边缘能量（越低越糊） | 2.93 | 1.80（< 纯插值 1.47 量级） |
| 8px 块边界比 blkR | 0.966 | 0.987（**无块纹**） |

**结论**：不是 8×8 块状马赛克（blkR≈1 无块界），是**严重模糊/涂抹**；且比"纯 LANCZOS 插值放大"还糊——说明二次去噪**没起到重建作用**。

## 根因（两层）

### ① latent 空间放大的固有限制
`LatentUpscaleBy ×2` 在 VAE 压缩空间（8× 压缩）插值——放大的是 latent 特征，不是像素。x2 倍率对 Qwen 这类大 VAE 已偏大，信息缺口大 → 糊。

### ② 差分扩散把 mask 二值化 + 参数组合过保守（**关键**）
读源码 `comfy_extras/nodes_differential_diffusion.py`：
```python
binary_mask = (denoise_mask >= threshold).to(dtype)   # mask 被二值化
if strength and strength < 1:
    blended = strength * binary_mask + (1 - strength) * denoise_mask
```
- 当前参数：`#37 SolidMask.value = 0.3`、`#38 DifferentialDiffusion.strength = 0.1`。
- `strength=0.1` → 几乎全用二值 mask（按 step 阈值分区），**大面积区域直接不去噪**。
- 叠加 mask 0.3 偏低 → **重绘强度过小**，插值糊无法被修正。

## 修法（两个方向）

### A. 快速可用（先保住"不糊"）
1. `#35 LatentUpscaleBy.upscale_method`：`bislerp` → 更稳的 **`bicubic`**（`bislerp` 在 Qwen latent 上易出伪影）。
2. **降倍率**：`scale_by` 2 → **1.5**（Qwen 大 VAE，1.5 更稳）。
3. **提高重绘**：`#37 mask 0.3` → **0.6~0.7**；`#38 strength 0.1` → **0.7~1.0**（让二次采样真正重建细节）。
4. 二次采样步数：当前复用 `#22`（12 步）。放大建议独立 **8~10 步、denoise 0.4~0.5**。

### B. 更高质量（重建而非插值）
- 放弃 latent 放大，改**像素空间放大**：`VAEDecode → ImageUpscaleWithModel(ESRGAN) → VAEEncode → 低 denoise 二次采样`。
- 或加 **Ultimate SD Upscale / 分块重绘**（Tiled）——但 Qwen 支持需验证。

### C. 逐参数排查（若想先定位单一变量）
按"只改一个变量"顺序试：先只降倍率 → 再只换 method → 再只提 mask。
