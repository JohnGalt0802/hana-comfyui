## 2. 幂等 / 异常 / 暂存清理

- **幂等**：`installOutputCapture()` 首行 `if (outputCaptureInstalled) return;`，尾部置哨兵 `outputCaptureInstalled = true`，多次调用只装一次监听器（与 `installQueuePromptCapture` 同款写法）。
- **异常**：每个监听回调整体包 `try/catch`，`executed`/`execution_success` 失败走 `console.warn(LOG_TAG, ...)` 吞掉；`execution_error`/`execution_interrupted` 清理失败静默。`reportHistoryImages` 自身再包一层 `try/catch`（含 `currentWorkflowInfo()` 内层 try）。上报为 fire-and-forget（`void reportHistoryImages(...)`），不回抛，绝不污染执行/画布链路。
- **暂存清理**：`execution_success` → 取出后立即 `pendingImages.delete(pid)`，仅有图时上报；`execution_error`/`execution_interrupted` → 按 `prompt_id` 删除该条（防泄漏）。`pid` 非法（非 string / 缺失）一律跳过。
- **只读**：监听器只读事件、只做上报，不改返回值、不改调用时机。
- **上报字段**与契约 §2.1 对齐：`{workflow, promptId, images:[{filename,subfolder,type}], at}`；`filename` 非 string 的 item 丢弃，`subfolder`/`type` 缺省补 `""`/`"output"`。去重由后端按 filename+subfolder+type 负责（重复上报无害）。
