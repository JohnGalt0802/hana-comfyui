# M6 · 环境自举（检测与安装引导）记录

**日期**：2026-09-21
**版本**：v0.2.0 → v0.3.0
**背景**：讨论「ComfyUI 本体能否随 App 打包分发」——结论：**不打包，走「检测 + 引导」**。

## 结论数据（本机实测）

| 项 | 体量 | 说明 |
|---|---|---|
| ComfyUI 代码（不含模型） | ≈ 0.32 GB | 仓库本体（含 .git） |
| venv（Python 依赖） | 5.43 GB / 53,883 files | torch 2.11+cu128 等 |
| **最小运行体（代码 + venv）** | **≈ 5.7 GB** | 未压缩；平台 / CUDA / Python 版本强绑定 |
| 模型库 | 50.89 GB | 因人而异，必然外置 |

**不打包的四个理由**：① 5.7 GB 起步的包体 + 装完还得下模型；② 一个包只能覆盖一种平台/CUDA/语言组合；
③ ComfyUI 周更节奏，打包即过期；④ 模型（几十 GB 起）必然由用户自己准备。
对照：官方 Desktop 同样是「首次运行按需下载」模式，不是全量打包。

## 交付内容（v0.3）

1. **中继安装探测**（`runtime/comfy-relay.mjs`）
   - 有限候选路径：盘根（C~G 盘 `ComfyUI` / `ComfyUI\ComfyUI` / `ComfyUI_windows_portable`）、用户目录（home/Desktop/Documents）、`%LOCALAPPDATA%\Programs\@comfyorgcomfyui-electron`、环境变量 `COMFYUI_PATH`；macOS/Linux 同理
   - 指纹：source（`main.py` + `folder_paths.py`）/ portable（`python_embeded` + `ComfyUI/main.py` 双指纹）/ desktop
   - 输出 `{ found, installs[{path,kind,version,hasVenv,mainPy}], candidatesChecked, probeAt }`；TTL 15s；**仅后端不可达时**附在 `/_relay/status` 的 `env` 字段
   - 诊断开关：`node runtime/comfy-relay.mjs --probe-env`（JSON 直出后退出）
2. **App 引导文案**（`index.js`）：`boot.note` 按「装了没跑 / 未检测到」分流（工作区三态视图 + 功能面板同源受益）；`status` 工具文本附探测行
3. **壳页引导条**（`ui/workspace.js|html`）：后端不可达时分流文案 + 「复制引导语」（启动/安装引导词）+「重试」；复制走 clipboard API + execCommand 兜底
4. **SKILL.md**：新增「环境不存在时」三步侦察（服务探测 → `--probe-env` → 分流处理）
5. **INSTALL.md**（新）：完整安装手册——Windows 主线（官方口径：Python 3.13 / cu130）、镜像（ghproxy / 清华源 / hf-mirror）、每步验证、排错表、平台变体
6. manifest / README / relay 头注释版本同步 v0.3.0
