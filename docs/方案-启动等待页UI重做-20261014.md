## 1. 现状（读实）

`app/ui/workspace.html` 三态视图（`view-booting` / `view-offline` / `view-error`），每态一个 `.panel`（标题 + sub + 转圈行 + meta + 按钮行 + 连接方式下拉 + 原始状态折叠）。

**问题**：信息平铺、无主次；"已等待 N 秒"埋在一行小字里；技术选项（连接方式下拉）常显；无进度感。

**真实功能对照（勿丢）**：
- `连接方式` 下拉（`#sel-mode` / `#sel-mode2`）：**真实功能**——iframe 装载 ComfyUI 的寻址方式（`direct`/`auto`/`sdk`/`raw`，见 `workspace.js` `buildFrameUrl` L831）。默认 `auto`（逐级回落）。**直连**能用绝对路径的自定义节点扩展，但 iframe 跨源（主题跟随停用）。
- `#off-wait`「已等待 N 秒」：起点 `svcWaitStart(proc, svcRequestedAt)`（**服务端 `proc.startedAt` 优先**），显示条件 `svcRequestedAt || proc.starting`——**与左栏 `panel-status.js` 逐字同源，口径不可改**。
- 按钮行为：`#btn-retry`/`#btn-retry2` = 重启中继；`#btn-reload-boot` = 刷新状态；`#btn-svc-start`（offline）= 启动服务；`#btn-svc-reload` = 刷新工作区。
- `#boot-meta`/`#off-meta`/`#err-meta` = 状态细节（describeBoot / setOffline 填）；`#boot-raw-wrap`/`#err-raw-wrap` = 原始状态折叠。
- 视图切换：`showView(name)`（`booting`/`error`/`offline`/`ready`），只切换 `.show` 类——**结构改造不能破坏这些 id 与语义**。

## 2. 设计稿（已认可）

**布局**：内容驱动高度的居中列（`min-height:460px`；**注意 workspace.html 是整页，可用 `absolute inset:0` 居中；但设计时先按流式做，整页再补居中**）。

**视觉语言**：
- **主标记**：细环（`--line`）+ 呼吸晕（`breathe` 3.4s）+ 旋转弧（`spin` 1.1s）+ 中心点脉冲（`pulse` 2.2s）。错误/完成态：停转、变色（`--bad`/`--ok`）。
- **标题**（小字 `--muted`）→ **状态主句**（15.5px/600）→ **计时**（30px 细体 `--accent` tabular-nums，主角）→ **三步轨**（中继 → 服务 → 前端：圆点 + 连接线，当前步呼吸波纹 `ripple`、完成步变绿、错误步变红）。
- **提示行**（`--faint` 11.5px）。
- **按钮**：幽灵按钮（`.gbtn`），主按钮 accent 描边。
- **「高级 ▾」**：默认收起，展开露出**连接方式下拉**（原 `#sel-mode`）。
- **配色**：浅/深两套（`body.t-dark` 同理改用现有 `body.t-dark` 约定——**必须对齐 workspace.html 现有 `body.t-dark` 类名**）。

**三态映射**（设计稿 → 现状视图）：
| 设计稿态 | 现视图 | 主句 | 计时 | 步骤轨当前步 |
|---|---|---|---|---|
| 启动服务 | `view-booting`（phase=starting） | 正在启动 ComfyUI 服务… | 显示（已等待 N 秒） | 服务（中继已完成） |
| 加载前端 | `view-booting`（phase 前进）/ `#ws-loading` | 正在加载 ComfyUI 前端… | 隐藏 | 前端 |
| 服务未起 | `view-offline` | ComfyUI 服务未运行 | 隐藏 | 服务（红） |

> **注**：现状 `view-booting` 同时承担"等中继"和"等前端 loading"；`#ws-loading`（80 行）是 ready 后的前端遮罩。新设计把"三步轨"引入后，`view-booting` 要按 `phase` 显示不同步。**具体拆分以执行单为准**。

### 3.2 `app/ui/workspace.js`（改状态驱动，逻辑内核不动）

`app/ui/**` → 同步宿主副本（`tools/sync-to-host.ps1`）+ 宿主重载/重启（ui 受 iframe 缓存，重启最稳）。
