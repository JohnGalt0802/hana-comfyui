# agent 打开工作流（共驾能力补齐）— 方案

日期：2026-09-27
状态：**探查阶段**（先测出真实 API，再实现）
背景：用户提出「agent 如何打开工作流，这也是人机共驾很重要的功能」

---

## 1. 问题

现在 hana_bridge 的 op 表全是围绕**当前这张图**的（读结构、改节点、存盘），
唯独**没有"换图"这颗按钮**。后果：

- agent 想改某张工作流，只能**求用户在界面上手动打开**
- 用户在别处时，agent 完全没法把"我要改的图"推到前台
- 共驾断链：能看到不等于能让对方看到

**目标**：加一个 op，让 agent 主动让前端打开指定工作流，且用户当场可见。

## 2. 已掌握的线索（实测，非推断）

### 2.1 现有代码里已在用的接口

hana_bridge 的 `js/hana-bridge.js` 里已经出现过：

| 接口 | 用途 | 出处 |
|---|---|---|
| `app.workflowManager.activeWorkflow` | 读当前工作流（`.name` / `.filename`） | `currentWorkflowInfo()` |
| `app.extensionManager.command.execute("Comfy.Undo")` | **命令系统**，已实测可执行 `Comfy.Undo` | `canvas.undo` op |
| `app.graphToPrompt()` | UI 图 → API 格式 | `canvas.prompt` |
| `app.graph.toJSON()` | UI 图全量 | `canvas.get` |

**关键推断**：`Comfy.Undo` 能执行，说明 ComfyUI 前端有一套**命令注册表**；
"打开工作流"很可能也是其中一条命令（形如 `Comfy.OpenWorkflow`），
或者是 `workflowManager` 上的方法。

### 2.2 外部检索结果

社区资料基本都在讲 **API 提交**（`/prompt`），没人讲**前端主动打开工作流**。
所以这条路没有现成答案，**必须实测**。

### 2.3 前端包形态

`comfyui_frontend_package/static`（前端 1.53.6）是 307 个打包压缩的 js，
硬读源码效率极低，且版本一变就失效。**不读源码，改实测。**

## 3. 探查方法

新增只读 op **`api.diag`**（与既有 `api.probe` 同类，属自检性质）：

- 报 `app.workflowManager` 的 own keys、原型方法名、`activeWorkflow` 字段
- 报 `workflowManager.workflows` / `openWorkflows` 的形状
- 报 `app.extensionManager.command` 的 own keys
- **把命令 id 列表里符合 `/workflow|open|load|tab/i` 的条目全捞出来**

原则不变：**只读、不改状态、不做任意 JS 执行**。

## 4. 预期实现（待 diag 结果确认）

目标 op：**`canvas.openWorkflow`**

```
canvas.openWorkflow { name | path }
  → 前端用官方入口加载该工作流
  → 返回值报告：打开了哪个、是否成功、失败原因
```

**实现要点（候选，按优先级尝试）**：

1. `app.workflowManager.openWorkflow(...)` 系方法（若 diag 报出）
2. `app.extensionManager.command.execute("Comfy.OpenWorkflow", {...})` 命令
3. 兜底：`app.loadGraphData(json)`（读文件 + 加载，绕开工作流管理器的历史记录）

**安全与体验约束**：

- **会覆盖当前未保存的改动** → 必须能查"当前图有没有未保存改动"（`activeWorkflow.modified`），
  有则**默认拒绝**，除非显式传 `force: true`。这条对应历史上那个"别静默破坏用户东西"的教训。
- 打开是**前端可见**的动作，天然满足"所有改动前端可见"的要求。
- 失败要给明确原因（文件不存在 / 已有同名未保存 / API 不存在），不静默。

## 5. 生效方式

| 改动 | 生效 |
|---|---|
| `js/hana-bridge.js`（前端扩展） | **刷新页面**（前端扩展在页面加载时注册） |
| `__init__.py`（路由） | 重启 ComfyUI |

diag 只动 js，**刷新页面即可**，不用重启后端。
