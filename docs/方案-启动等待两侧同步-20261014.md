# 方案 · 启动等待计时「两侧同步 + 左栏醒目」（2026-10-14）

> **需求**（John 2026-10-14 凌晨）：hui 启动等待期间，**宿主最左侧栏（panel）** 与 **工作区壳页的启动等待覆盖层（画布框）** 显示不同步，要拉齐；且**左侧栏要更醒目**。

---

## 1. 现状：两处各自计时，起点不同源

| 位置 | 文件 | 起点变量 | 置位时机 | 显示元素 |
|---|---|---|---|---|
| 左栏（宿主最左） | `app/ui/assets/panel-status.js` | `svcStartAt` | **只在左栏点「启动服务」时** `startService()` 置位（L506） | `#p-note`（`renderSvcWaitNote` L465） |
| 壳页覆盖层（画布框） | `app/ui/workspace.js` | `svcRequestedAt` | **只在壳页点「启动服务」时** `startBackend()` 置位（L718） | `#off-wait`（`showOffline` L768） |

**病灶**：
- 从哪侧点启动，**只有那侧**才有起点 → 另一侧无计时（或残留旧值）。
- 两侧哪怕都点过，起点也是两次点击各自的时间，**天然对不上**。
- 页刷新/两页实例各自独立 → 更不一致。

**两侧还有一处口径差异**：左栏 `renderSvcWaitNote` 会叠加「（服务端标记：启动中）」，壳页只显示「已等待 N 秒」——同一件事两种说法。

---

## 2. 可用的唯一源头：服务端权威字段（已存在，无需新增后端）

中继 `comfy-relay.mjs` 的 `backendProcPayload()`（L1707）经 `backend.proc` 下发：

- `startedAt`：**本次启动受理时刻**（ISO 字符串）。写入状态文件（`saveBackendState`），**中继重启后可恢复** → 天然跨页一致。
- `starting`：布尔，启动是否在途。
- `lastStartResult`：`{at, ok, accepted|error}`——最近一次受理结果。
- `lastStop`：`{at, …}`——停止时刻（用于判断「本次启动是否晚于上次停止」）。

**这是两侧应当共用的唯一源头**。两侧的 `state` 快照里都能拿到 `relay.backend.proc`（壳页 `getFullStatus()`、左栏 `st.relay.backend.proc`）。

---

## 3. 修法

### 3.1 计时起点统一到服务端 `proc.startedAt`

两侧各自的「等待起点」改为：

```
起点 = proc.starting === true ? Date.parse(proc.startedAt || lastStartResult.at) : 0
```

- `proc.starting === true` 且 `startedAt` 有效 → 显示「已等待 ⌈(now - startedAt)/1000⌉ 秒」。
- 不再依赖本页 `svcRequestedAt` / `svcStartAt`（**本地起点降级为兜底**：仅在服务端字段还没到位、而本页刚点过启动的极短窗口内使用，避免点击到快照刷新之间闪空）。
- 收尾口径一致：`reachable` → 结束；服务端 `lastStartResult.ok === false` → 失败。

### 3.2 两侧文案对齐

两侧统一为：`等待 ComfyUI 就绪 · 已等待 N 秒`（左栏可保留「（服务端标记：启动中）」的补充，但主句一致）。壳页 `#off-wait` 与左栏 `#p-note` 的主计时句式必须同一模板。

### 3.3 左栏更醒目（John 点名）

`panel.html` 现状：`#p-note` 是 `.note`（`color: var(--text-muted); font-size: 11px`）——**灰色小字，不醒目**。
方案：
- 新增 `#p-wait`（或给 `#p-note` 加 `.wait` 类），等待期用**独立醒目行**：`font-size: 13px`、`font-weight: 600`、`color: var(--accent)`、`font-variant-numeric: tabular-nums`，与壳页 `.panel .wait`（13.5px / accent / 600）**视觉统一**。
- 位置：紧贴「启动服务」按钮下方（或状态折叠区顶部常显），确保不展开折叠也看得见等待秒表。
- 非等待态恢复 `#p-note` 的常规灰字样式（零视觉噪音）。

### 3.4 边界

- **不新增常驻定时器**：左栏已有 `svcWaitTimer`（1s tick）、壳页已有 `statusTick`（1.5s）——复用，不自建。
- **不改中继/py/桥**：只用已下发的 `proc.startedAt`/`starting`。
- 页面离线（中继不可达）时无服务端字段 → 回退本地起点显示，并示「待中继恢复确认」。

## 5. 验收标准

1. **同源**：同一时刻，左栏与壳页覆盖层显示的「已等待 N 秒」**差值 ≤ 2 秒**（同一源头，仅采样时刻差）。
2. **跨侧一致**：从**左栏**点启动 → 壳页覆盖层也显示计时；从**壳页**点启动 → 左栏也显示计时。
3. **跨页刷新一致**：任一页刷新后，计时不归零、不回跳（因源头是服务端 `startedAt`）。
4. **醒目**：等待期左栏出现 accent 色、加粗、字号 ≥13px 的独立计时行；非等待期恢复灰色小字。
5. **零回归**：就绪/失败/超时收尾行为不变；`setInterval` 数量不变。
