## §2 板块摘要

### 2.1 入口 / 工具 / 路由（`app/index.js`）
- **工具面**：单一 Agent 工具 `comfyui`（L4840 注册），11 个 action 经 switch 派发（L4864-4914）：`status / submit / query / result / cancel / service / workflows / upload / update / canvas / window`。
- **路由面**：26 条 `/comfyui-hana/*` 路由（L4931-5405），按前缀 6 组：状态类、服务起停、`shell/*` 壳页桥、`update`、theme、`keepalive-probe-ping`。
- **shellBridge**：壳页桥**单桶**四原语 `hello/poll/result/status`（L2086-2103 / 5064-5120）——同刻仅一壳页。
- **任务桥**：`submit → tasks.create → jobTick(2s) → settleJob`（L1379 / 708 / 5422），生成即宿主任务卡。
- ⚠️ **不一致点**：`app/session.stage-file` 出现在能力调用里，**未进 manifest capabilities 清单**（待核）。

### 2.2 桥前端（`app/bridge/js/hana-bridge-23033000.js`）
- `OPS` 表（L1470）管画布读写；`WRITE_OPS` 白名单（L7335）管写拦截；`runPatchTransaction`（L1095）管意图级多事务（即时 verify + 逆序原子回滚 + 复合逆操作压栈）。
- **提交 HEAD（2026-10-23 改）**：HEAD 由后端 `.head.json` 持有，前端不落 localStorage。提交上报**不传 parent**（后端按「显式 parent > .head.json > 索引末条」决定）；回跳成功后 POST `history-head-set`；提交树小黄点读 `historyTreeHead`（来自 `history-list` 响应的 `head` 字段）。历史包袱：`fetchAuthoritativeHeadSeq`、`historyHeadGet/Set`、`HISTORY_HEAD_LS_PREFIX` 均已删除。
- **live 分组能力（2026-10-13 新增）**：`canvas.addGroup`（L2181）/ `setGroup`（L2234）/ `removeGroup`（L2274）——活画布上建/改/删分组框，用前端 `window.LGraphGroup` + `graph.add`（**纯对象不行**：序列化调 `serialize()`、`graph.add` 只认 `instanceof LGraphGroup`）。支撑函数 L1215-1320（`lgraphGroupCtor`/`liveBoundsForNodes` 自动算框含 PAD=20/`locateLiveGroup` 按 index|title）。三 op 进 `WRITE_OPS`、不豁免副驾驶。
- **提交历史（最大块）**：落盘 `/hana_bridge/history-commit`、常驻捕获（`installQueuePromptCapture` L2944 包装 `api.queuePrompt`）、弹层 bar、**泳道树（内联 `commitGraphLanes` L6395）**、回跳（`historyRollbackExecute` L5746）、树刷新（`historyTreeRefresh` L6867）、缩略图/lightbox、框视角过滤。
  - ⚠️ 桥内行号随每次改名漂移（高 7K 行），**按函数名定位，别按行号**；上表行号为 2026-10-23 快照。
- **copilot**：开关 / visual 锁与高亮（L1599-1700）。
- **探针**：throttle-probe 心跳 + keepalive poke 应答。
- ⚠️ **三条硬约束**（详见 §3）：`node --check` 假绿 / CSS 注释只能用 `/* */` / `commit-graph-lanes` 内联版须同步。
- **画布写路由的定向机制**（2026-10-13 实做坐实）：写/读 op 带 `workflow=<名>` 时，py 只认「**当前前台活动标签**」的名字；**同页非前台标签不可达**（A 档缺口，`openWorkflows` 采集已改、待部署）。后台标签被浏览器节流会判「过期」跳过（踩坑 #30）。
- **`ComfySwitchNode` 是 lazy**（`comfy_extras/nodes_logic.py`）：`check_lazy_status` 只求选中侧 → **未选中分支整条不执行**。这是 hui 画布上所有「开关切模式」支路的成立基础。

### 2.2·补 桥的「两腿」与多标签能力（2026-10-13）
- **两腿**：`canvasBridgeInvoke`（`app/index.js`）优先壳页腿（`app/ui/workspace.js` `shellOp`），失败回退扩展腿。关键：**壳页腿是手写白名单、只判 `ok` 不校验形状**。
  - ⚠️ **硬约束（两腿一致性）**：壳页腿若「支持某 op 但返回简化形状」，会**遮蔽**真实（py/桥）结果。已发生：`canvas.pages` → 已加 `SHELL_LEG_SKIP`（`app/index.js` ~L2105）强制走扩展腿。
  - **只在「py 直答、两腿同时可达」的 op 上才需 SKIP**；依赖前端扩展的 op（summary/exec.running/openWorkflow…）两腿实际**互斥**（代理模式扩展腿 403 死），盲加 SKIP 反而失能。
- **多标签能力（agent native，2026-10-13 补齐）**：桥采 `openWorkflows`（`openWorkflowsInfo()`）+ 新增 `canvas.activateWorkflow`（切已打开标签到前台）；py 账本记 `openWorkflows`、定向支持标签级寻址（`allow_bg`）；app 登记 op + `target_not_foreground` 友好文案。详见 `docs/规划-agent-native缺口-多标签维度-20261013.md`。

### 2.3 桥后端（Python）与中继（Node）
- 桥 py 在 **8188 进程内**注册 12 个端点；`/call` 校验 `X-Hana-Token`，其余及 `history-*` 端点只认 **8188 同源**（P1-D1，不校验 token）。
- `history-*` 家族：`commit` / `save` / `attach-images` / `list` / `snapshot` / `migrate` / **`head-set`（2026-10-23 新增）**。
- `history_store.py` 纯落盘：`index.jsonl`（v2 字段含 `parent/kind/sig/blocks/delta/runs/mergeInto`）+ `NNNN-*.json` 快照 + `.images.json` sidecar + **`.head.json`（2026-10-23 新增：当前 HEAD，`{"seq","at"}`，与 index 同级，原子写）**；**合并判定：仅 `kind=run` 且签名相同才写 `mergeInto` 标记行**。
  - HEAD 读规则：`read_head` 缺失 / 坏 JSON / 指向非主行（mergeInto 行或已删 seq）→ `_head_seq_or_last` 退回索引末条主行。
  - `migrate_history` 对 HEAD 的处理：不进「余留文件」搬运；整体搬移随目录走；**合并分支写盘后把目标 HEAD 校正为合并后末条主行**（否则迁移后首次提交凭空长泳道）。
- 中继 `comfy-relay.mjs`：受管 Node 进程，**全量反代 `127.0.0.1:8188`**，管起停/指标/状态。
- ⚠️ **弃用档案**：`app/runtime/history-commit.mjs` 已弃用、**无调用方**（落盘走桥 py 直写）。

### 2.4 lib 纯模块（`app/lib/*.mjs`）
- **语义读四件套**：`canvas-project / canvas-analysis / canvas-outline / canvas-diff` → 统一依赖 `canvas-symbol` → 由 `workflow-file.mjs` 聚合消费。
- **写通道**：`canvas-edit`、`canvas-history`、`canvas-open-workflow`、`workflow-tools`（各服务对应 endpoint/桥）。
- 全部零运行时依赖、可 `node xxx.test.mjs` 独立跑；仅 `canvas-history` 引入 `node:path`；`workflow-tools` 单测 `workflow-tools.test.mjs`（24 条，2026-10-31）。
- **`workflow-tools.mjs` 的 UI→API 转换器（2026-10-31 起含子图展开 v1、静音/旁路语义、拒绝归因）**：
  - **`declaredWidgetSlots(info, node)`**：按「声明序」枚举节点占据 widget 位（`widgets_values` 位置序）的输入，返回「输入名 → 位置」Map。有槽证据（内部节点 inputs 带 `widget` 标记、剔除 socketless）按槽序，无槽证据回退 object_info 声明序（required+optional、剔 forceInput）；两条路径都含 `seed`/`noise_seed` 的 `control_after_generate` 副值跳格。**主循环写位置与子图展开传值共用这一份实现，禁止两套口径漂移**（踩坑 #61）。
  - **`subgraphWidgetIndexOf(objectInfo, node, targetSlotIdx)`**：目标输入名 → 声明序 widget 位置；未知类型/名字不在声明里 → null（不猜，调用方拒绝并点名）。
  - **`slotOrderWidgetIndexOf(node, targetSlotIdx, wv)`**：槽序近似定位（旧口径），只用于未知类型时的只读现值比对（判异同 → 放行或拒绝），**绝不用于写位置**。
  - **`expandSubgraphs(wf, problems, objectInfo)`**：子图展开 v1，主流程最前调用；无 definitions.subgraphs 或无实例原样返回。实例 id 重映射 `s<实例id>:<内部id>`、link `s<实例id>L<原linkid>`；接口按 `origin_id=-10 / target_id=-20` 直连。widget 值**按名字对位**（踩坑 #64：三轴不同轴，任何下标口径都会在 9/15/13 这类样本上把参数写错位且零告警）：`defByName`（定义输入名 → 定义下标，主对位表）、`defDupNames`（定义内重名输入，命中即拒绝）、`inputBySlot`（定义下标 → `-10` 链接的内部消费端，接口连线改接与写值共用）、`usedInputs`（已被外部连线占用的定义下标，防多线同槽）。named 优先逐键对名；无 named 按定义序 widget 输入回退、项数不符拒绝；named 与位置值分歧拒绝。约束：**实例 `inputs` 只是定义输入的子集**（socket 与暴露的 widget），不得当全量槽表。拒绝边界（嵌套/实例 mode 2/4/无法定位且值不同/结构异常/接线歧义/实例槽名不在定义里/named 与位置值分歧）→ 整份拒绝并点名。设计口径见 `docs/设计-SetGet适配与提交树取根图-20261030.md` §九。
  - **mode 预扫**：转换前扫全图 mode；mute(2) 断链不执行，bypass(4) 按类型穿透（复用 `pickEntry`：同名 → 唯一同类型 → 歧义拒绝），未知 mode 仍拒绝。
  - **`deadWhy(lid)`**：连线缺失类报错的末尾归因（上游是谁、处于什么状态），配合 mode 预扫消除次生噪音。
  - **`summarizeProblems(list)`**：报错末尾的分类汇总（`共 N 项阻断，分类：…` + 装插件/写档案建议），只拼文案不参与判定，不导出；既有报错文案逐字未变。
- ⚠️ **`commit-graph-lanes.mjs` 不被任何 app 文件 import**——它是**桥内联版（`commitGraphLanes`，L6395）的镜像参考 + node 单测载体**；**改 lib 必须同改桥内联版与 test 断言**。2026-10-23 已与桥的「单遍插入式分配」对齐（`assignLanesRaw` / `countCrossings` / `countLaneHops` / `scoreOf`，返回含 `cost`），单测 12 例。
- **节点适配档案（`app/lib/node-adapters/*.json`，共 18 份）**：转换器按**类型字符串精确匹配**消费（踩坑 #63）。内置虚拟件 5 份：`Reroute`（reroute.json）、`SetNode`、`GetNode`（pull 规则，见 0.18.0）、easy 对应 `easy_setNode` / `easy_getNode`；rgthree 13 份（`rgthree-*.json`）：12 个纯前端件（Fast Muter/Bypasser 系列——控件状态存在目标节点 `mode` 里，丢控件安全——及 Bookmark/Label/Node Collector/Combiner/Mode Relay/Mode Repeater/Random Unmuter）+ `Reroute (rgthree)` 的 passthrough。**真后端节点（`Context (rgthree)` 等 26 个）一个档案都没写**——写了伪 passthrough 会静默断供。写法见 `app/skills/comfy-node-adapter/SKILL.md`。

## §3 硬约束与坑（改代码前必读）

1. **桥文件校验**：桥含 `import`，`node --check` 是**假绿**（漏报同块重复 `const`）→ 必须 `node tools/check-bridge-syntax.mjs <桥>`（踩坑 #42）。
2. **桥内 CSS**：样式写在 JS 模板字符串里，注释只能 `/* */`，**用 `//` 会破坏 CSS**。
3. **泳道算法双份**：`app/lib/commit-graph-lanes.mjs` ↔ 桥内联版（`commitGraphLanes`，L6395）**逐逻辑一致**，改一处必须同改两处（含 `.test.mjs` 断言）。
4. **`BRIDGE_BUILD_TAG` 三处同源**：js 文件名 = js `BUILD_TAG` = `app/bridge/__init__.py` 的 `BRIDGE_BUILD_TAG`。改名换版三处一起改。当前：`2026-10-23 hana-bridge-23033000`。
6. **提交 parent 只能由后端定（2026-10-23 起的硬约束）**：前端提交路径**不许**再往 body 里写 parent；回跳要改 HEAD 就 POST `history-head-set`。谁在桥里重新引入「用索引末条当 parent」的逻辑，分支功能会立刻退化成单链（历史事故见 M20261023 记录）。
7. **仓库与运行副本漂移检查**：部署前先跑 `tools\deploy-bridge.ps1 -Status`；改了运行副本必须回写仓库，否则下次 sync 会用仓库旧版覆盖。
5. **零改动铁律**：不碰 ComfyUI 源码与前端打包产物；一切经 custom_nodes 桥 + App 机制。
