## 一、形态（John 定，逐条落实）

**提交历史框** = 锚在分组框标题栏**上方**的一段横向时间轴。

```
        ┌──────────────────────────────────────────┐
        │ 2. Prompt & size · 7 次提交           ✕ │ ← 头部
        │  ▏ ▏▍ ▏ ▏▍▍ ▏  ← 刻度（左旧右新，按时序）│ ← 横轴
        │ 10:02                          11:47     │
        └──────────────────────────────────────────┘
        ┌──────────────────────────────────────────┐
        │ 2. Prompt & size                         │ ← 分组框标题栏
        └──────────────────────────────────────────┘
```

- **默认态**：只有横轴 + 刻度，无其他内容
- **触发**：点 bounding 框弹出；再点（或点空白/✕）关闭
- **降级**：无 bounding 框时作用于功能块（角色块）——沿用现有 `graphBlocks` 命中逻辑，已支持
- **排布紧凑**

## 二、三段交互

| 动作 | 反馈 | 数据 |
|---|---|---|
| **悬停**刻度 | 同主题**气泡**：时间 + 较上次变更的**节点名** | `at` + `delta.changed[].title` |
| **单击**刻度 | 展开该提交的**缩略图**；鼠标移走自动关 | `runs[].images` → P4 的 `historyImagesFor` |
| **双击**刻度 | 确认框「回到该提交节点」 | 复用 P3 的 `historyRollbackExecute` |

- 单击/双击消歧：240ms 内二次点击 = 双击（现有 P3 demo 卡就是这个逻辑，直接搬）
- 缩略图**多张时可横向滚动**（合并提交）
- 点缩略图 → 原图 lightbox（P4 已做 `historyOpenLightbox`）

## 三、四色

刻度颜色 = `(source, kind)`：
- 色相分谁：`user`=冷色（`--u-run` 蓝系），`agent`=暖紫（`--a-run` 紫系）
- 形态分跑/存：`run`=实心，`save`=空心环

## 四、刻度堆叠色条

每根刻度上堆叠细色条，示意该提交触及了哪几个块（沿用「全局提交轴」视觉）：
- 色条数 = 该提交 `blocks` 的长度；命中本框的条高亮
- 单框视图里，本框命中=高亮色，其他块=灰
