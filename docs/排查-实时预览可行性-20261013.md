# 排查：ComfyUI 每步降噪预览能否实时进卡（2026-10-13）

**问题**：John 问「生图每一步降噪的过程能实时预览吗」。
**结论**：**机制上能，当前环境不能**——被三处挡住，且三处都可修。

---

## 一、ComfyUI 侧的机制（已读源码坐实）

- 采样每步回调 `prepare_callback`（`latent_preview.py`）→ `pbar.update_absolute(step+1, total, preview_bytes)`。
- 预览图有两种解码方式：
  - **`latent2rgb`**：无需模型，直接用 latent_rgb_factors 矩阵投影（**无需额外文件**，效果一般）。
  - **`taesd`**：需 `models/vae_approx/` 下的 TAESD 解码器模型（**画质好得多**）。
- 发送：`WebUIProgressHandler.update_handler` → `send_sync(BinaryEventTypes.PREVIEW_IMAGE_WITH_METADATA, (image, metadata), client_id)`
  - **二进制 WS 帧**（不是 JSON 文本）
  - **只发给 `client_id`**（发起该 prompt 的客户端）

## 二、三处关卡（实测）

| # | 关卡 | 现状 | 修法 |
|---|---|---|---|
| **1** | **预览默认关闭** | 启动命令 `main.py --listen --port 8188 --enable-manager`，**无 `--preview-method`** → 默认 `NoPreviews`（`cli_args.py` 默认值） | 启动参数加 `--preview-method taesd`（或 `latent2rgb`） |
| **2** | **TAESD 模型未装**（仅 taesd 路需要） | `models/vae_approx/` 空 | 下 TAESD 解码器（约几 MB） |
| **3** | **中继丢弃二进制帧** | `handleBackendEvent(text)` → `JSON.parse(text)` 失败即 `return`；预览是二进制帧 → **被直接丢弃** | 中继需识别二进制帧、取 `PREVIEW_IMAGE_WITH_METADATA` 的图、转 base64 存进 prompt 记录 |

**好消息**：中继 ws 订阅与提交**用同一 clientId**（`--client-id`，L1945 订阅 / L2546 提交带 `client_id`）→「预览只发给发起者」**不构成障碍**。

## 三、改造成本分级

### A. 最小可用（先看到"能预览"）
1. ComfyUI 启动参数加 `--preview-method latent2rgb`（**无需模型**）。
2. 中继解二进制帧 → 存最近一帧到 prompt 记录（`previewB64`）。
3. 卡片：进度轴旁显示这张小预览图（几帧一跳）。
- **代价**：中继改一处（解帧）+ 启动参数；**画面较糊**（latent2rgb 是投影）。

### B. 高质量（推荐，真正的"看着成像"）
在 A 基础上把 `--preview-method` 换 `taesd` + 装 TAESD 模型。
- **代价**：多下几 MB 模型；画面接近成品。

### C. 更完整（预览帧序列）
中继保留**最近 N 帧**（而非只最后一帧），卡片可回放"从噪点到成图"。
- 需要卡片侧加一个小播放器；中继多存几帧。

## 四、几个已知边界（如实）
- 预览是 **JPEG 小图**（`MAX_PREVIEW_RESOLUTION` 默认 512），**不是成品质量**——它是"看过程"用的。
- 预览频率 = 采样步频（每步一帧），我们**可降采样**（如每 2 步取一帧）省带宽。
- **只对走画布/后端的、带采样器的 task 有效**；非采样节点无预览。
- **多任务并发时**：预览按 client_id 区分，中继单 clientId 下按 prompt_id 归属。

## 六、修正：开关可免重启（2026-10-13 复核）

**发现**：`execution.py:733` → `set_preview_method(extra_data.get("preview_method"))`。
**含义**：**每次提交工作流的 `extra_data` 可带 `preview_method`** —— 中继提交时带上即可，**无需改启动参数、无需重启 ComfyUI**。设置页开关可**即时生效**。

**由此修正实现形态**：
- 不再需要 "启动加 --preview-method + 重启"；中继在 `POST /prompt` 的 `extra_data` 里带上 `preview_method` 即可。
- 预览方式可分两档（免重启切换）：
  - `latent2rgb`：**零额外模型**（用内置矩阵投影）——基础档，**无需下载**。
  - `taesd`：需 `models/vae_approx/` 下载 TAESD 解码器（几 MB）——高清档，**按需下载**。

## 七、概念澄清（与 John 的"加装依赖"对齐）

要分清两类东西，落点不同：
| 类别 | 内容 | 放哪 |
|---|---|---|
| **代码能力** | 中继解二进制帧、卡片显示预览、设置页开关 | app 自带（仓库），**不是"依赖"** |
| **模型文件** | TAESD 解码器（仅 taesd 档需要） | **选装目录**：`models/vae_approx/`（ComfyUI 模型区，非 app 包内） |

→ John 的"按需下载、不撑大 app"成立：**要下载的只有 taesd 那几 MB**，且它天然属于 ComfyUI 的模型区（`vae_approx`，`folder_paths` 动态扫描，装上即用）。

**两级设计（推荐）**：
- **基础档（免下载）**：`latent2rgb` → 开了就能看，画面较糊。
- **高清档（按需下载）**：`taesd` → 设置页点"下载预览模型（约几 MB）"→ 落 `models/vae_approx/` → 即时可用。
