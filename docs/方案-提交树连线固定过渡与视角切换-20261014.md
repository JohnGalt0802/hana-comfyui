# 方案 · 提交树连线固定过渡 + 视角切换（2026-10-14）

> **用户需求**：
> ① 跨泳道连线「分得更快」——用**固定的 x 轴长度**完成过渡，剩下的**用直线连接**。
> ② 提交树加**视角切换**：时序视角（现状）↔ 紧凑视角（分支直接对齐到分支节点的后一格位置，整个树不再按时序留空位）。

---

## 1. 现状（已读实，`hana-bridge-14180030.js`）

### 布局（`historyTreeRenderTree`，L5295）
- `shownNodes` = 可见节点（seq 升序）；`rankOf` = seq → rank（0 起）。
- `colW = clamp(16..56, (availW-24)/n)`；节点 `left = (rank+0.5)*colW`；`W = n*colW`。
- **x 完全由全局 rank 决定** → 分支点离父多远，取决于 seq 间隔。

### 连线（`historyTreeDrawEdges`，L5831）
- 同 row → 水平直线。
- 跨 row → **整段非对称 S 曲线**：`M xr,pcy C (xr+k1),pcy (xl-k2),ccy xl,ccy`（k1≤14+idx*5、k2≤56）。
- 问题：k2 最大 56 → 曲线在子端"铺得远"，观感不干脆。

---

## 2. 改动①：固定过渡段 + 直线

跨 row 连线改为**两段**：
```
M  xr   pcy
C  (xr + T/2)  pcy   (xr + T/2)  ccy   (xr + T)  ccy     ← 过渡段（固定水平宽 T，S 弧）
L  xl   ccy                                               ← 直线段（水平）
```
- `T = 16px`（固定过渡水平宽度；`tw = min(T, dx*0.6)`，父子里得很近时压缩）。
- 过渡段仍用三次贝塞尔（两端水平切线，平滑换道），但**水平投影固定**，不再随 dx 拉长。
- 收尾为纯水平直线 → "分得更快、更干脆"。
- 同 row 连线不变（直线）。折叠淡出线不变。

---

## 3. 改动②：视角切换（时序 / 紧凑）

### 状态
- 新增 `historyTreeViewMode`（`"time"` | `"compact"`），默认 `"time"`（保持现状）。
- 持久化：`localStorage` key `hana.historyTreeView.v1`（按页可不必分槽，全局一种即可）。
- 读写 helper：`historyTreeViewGet()` / `historyTreeViewSet(m)`。

### 布局差异（仅 x 轴）
- **时序 `time`**（现状）：`x(seq) = rank(seq)`；`maxX = n-1`。
- **紧凑 `compact`**：`x(seq) = x(parent)+1`（父不在可见集/无父 → 0）；`maxX = max(x)`。
  - 即「分支对齐到分支节点的后一格位置」；同一 x 的多节点因 row 不同不重叠。
  - 实现：按 seq 升序遍历 `shownNodes`，`xOf` 递推；`parent` 用 `bySeq.get(seq).parent`。
- `colW = clamp(16..56, (availW-24)/(maxX+1))`；`W = (maxX+1)*colW`；节点 `left = (x+0.5)*colW`。
- **切换时**：保持滚动位置合理（切到紧凑 → 内容变窄，`tcanvas.scrollLeft` 归 0；切回时序同理）。

### UI
- 收纳条（`collapsed`）新增一个**视角切换按钮**（在「存档当前画布」旁）。按钮显示当前视角（如 `时序` / `紧凑`），点击切换并重渲染。
- 持久化读取后首渲染即用对应视角。
- `historyTreeRenderTree` 末尾调用处不变（内部读 `historyTreeViewGet()`）。

## 6. 验收

1. 跨泳道连线：过渡只占固定一小段，之后水平直线；观感更干脆。
2. 时序视角：与现状一致（x 按 rank）。
3. 紧凑视角：分支节点紧贴父的后一格；整体不再按时序留空；无节点重叠。
4. 视角按钮可切、刷新后记住上次选择。
5. 既有功能（hover 气泡、预览、回跳、点外部关闭、存档）不受影响。

---

## 7. 待确认的理解假设（若不符请指出）

- 「紧凑视角」= **子 x = 父 x + 1**（拓扑紧排）。若你是指「每个泳道各自从 0 开始编号」，语义不同，实现要向另法调。
- 固定过渡长度 **T=16px**（可调）。
- 默认视角保持**时序**。

## 8. 迭代2（2026-10-14，用户反馈）

**用户反馈**：① 默认改用**紧凑**；② 分支节点距离拉大，给过渡留空间，曲线相切处斜率变化率（曲率）低一点；③ 双击回滚窗回归（另见诊断）。

**根因（实测几何）**：大树时紧凑视角 `colW` 触底下限 16 → 父子间隙 `dx = colW - nw ≈ 8.8px` → 过渡宽 `t = min(16, dx*0.7) ≈ 6.2px`，而落差 36px → 端曲率 `κ = 4h/t² ≈ 3.75`（陡如折角）。

**改法**：
| 参数 | 现状 | 改为 | 效果 |
|---|---|---|---|
| `colW` 下限 | 16 | **26** | 拉大列距，给过渡留空间 |
| `nw` 系数 | 0.45 | **0.30** | 节点更瘦，间隙更大 |
| 过渡 T | 16 | **26** | 固定过渡更宽 |
| 过渡占比 f | 0.70 | **0.95** | 充分利用间隙 |
| 默认视角 | time | **compact** | 按用户指示 |

新几何（大树紧凑）：`colW=26, nw=7.8, dx=18.2, t=min(26, 17.3)=17.3, κ=4·36/17.3² ≈ 0.48`（较现状 3.75 **降约 7.8 倍**）。

曲线保持对称三次贝塞尔（两端水平切线，即**两端与直线相切**）：`M pr,pcy C (pr+t/2),pcy (pr+t/2),ccy (pr+t),ccy L xl,ccy`。
