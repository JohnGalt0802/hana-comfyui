# 方案：Qwen21 质量版 · 生图/编辑一体开关 + 专用编辑工作流

- 日期：2026-10-03 ｜ 主脑撰写 ｜ 状态：**已完成**（W1/W2 实测通过，验收合格）
- 背景：用户要求在「Qwen21 t2i 质量版」基础上加入「编辑生成好的图像」分支，用一个开关控制生图/编辑；另要一个专门的图像编辑工作流。前置要求：先调研社区，避免重复造轮子。
- 调研：见 `docs/调研-Qwen21-编辑工作流-20261003.md`（专用编辑方向）；社区一体式方向由主脑 anysearch 补充（结论见下）。

## 一、调研收口（关键结论）

1. **社区无完全对标的现成「一体开关式」工作流**：
   - `foprc/qwen-image-2.1-comfyui-workflow`：同一 Boolean 驱动多个 If/Else Switch、断线式参考图接入、latent 来源切换——结构与我们所需完全同构，但用途是「深度图参考」非编辑指令；GGUF 依赖不符本机。→ **借鉴其结构**。
   - `kuraneko1/qwen21-fast-comfyui`：自研单节点通吃 t2i/edit，但 Linux 向、两个独立工作流（非一体开关）。→ 仅记录。
   - B站「多功能一体化」（BV13saX6UEvg）：RunningHub 云端分发 + 两个自定义节点仓库，形态不符。→ 排除。
   - 官方机制：`TextEncodeQwenImage21`（image 输入 + latent 输出）+ `ComfySwitchNode` 在空 latent/图像 latent 间切换（官方 edit 模板、foprc 同款）——**即社区通用做法，直接采用**。
2. **专用编辑工作流**（现成，直接用）：
   - 主推：Viggle turbo edit（6 步、无 CFG、自带 QwenImage21Cache；本机 viggle_turbo.py 节点已装、LoRA v0.2.1 已有）。
   - 质量备份：官方 edit 模板（本地已有 `qwen21-templates/qwen21_official_image_edit.json`；注意加载器默认 int8，本机需选 bf16）。
3. 本机模型齐备（bf16 底座 + VAE + CLIP），无需下载模型（仅 v0.3 LoRA 可选升级）。

## 二、一体版设计（基于 (00007) 质量版）

### 结构（新增 6 个节点 + 3 处改线）

```
[新] PrimitiveBoolean「Edit mode」 ─┬─→ S1.switch
                                    ├─→ S2.switch
                                    └─→ S3.switch

[原] #8 EmptyLatentImage.LATENT ──→ S1.on_false
[原] #18 TextEncodeQwenImage21.latent ──→ S1.on_true
        S1.output ──→ #23 SamplerCustomAdvanced.latent_image（原 link32 改道）

[原] #16 ComfySwitchNode.output（PE 链末端）──→ S2.on_false
[新] PrimitiveStringMultiline「Edit instruction」──→ S2.on_true
        S2.output ──→ #18 TextEncodeQwenImage21.prompt（原 link20 改道）

[新] LoadImageOutput「参考图（从输出目录选）」──→ S3.on_true
        S3.on_false = 空（断线式）
        S3.output ──→ #18 TextEncodeQwenImage21.images.image_1
```

- 语义：开关 OFF=生图（原链路完全不动）；ON=编辑（参考图进编码器、latent 改为图像 latent、prompt 改为编辑指令）。
- 设计决策与依据：
  - 三 Switch 同驱一 Boolean（foprc 验证过的模式，用户只需拨一处）。
  - S3 断线式（关=无图入码器；避免生图模式白白编码参考图；foprc 明示此做法）。
  - 编辑指令独立输入（生图词与编辑词分开，切换不用改文案）。
  - `LoadImageOutput` 内置节点：直接选 output 目录里生成好的图（"编辑生成好的图像"落点）。
  - 采样参数与 t2i 共享（不拆参数切换，避免过度设计）；编辑模式建议参数写入 note。
  - 不加 QwenImage21Cache（V1 保持最小变量；实测需要再优化）。
- 用户须知（进 note）：ComfyUI 是单向流水线，生图与编辑是两次执行，开关控制单次走哪条分支。

### 发现并记录（hui app 侧 → `docs/待办与验收清单.md`）
- B6：中继 UI→API 转换器不支持 autogrow 动态输入（两个工作流均复现；widget 错位连原节点都会中招）
- B7：`workflows(name)` 文件名含「+」时读取失败（encodeURI 漏编 `+`；raw `+`→502 / `%2B`→200）

### 已知限制（面向使用）
- 生图与编辑是两次执行（ComfyUI DAG 单向，无法一次出两图）
- 一体版编辑画布跟随参考图（resolution=1024 折算；需原像素可设 0）；编辑指令英文最稳、`<image1>` 引用
- v0.3 LoRA 未下载（可选升级，附 URL 与步骤；替换 `lora_name` 即可）
- PE（Enhance prompt）两条工作流均保持关闭（本机现状；启用需 PE 编码器验证）
- 一体版模板名含「+」暂不能按模板名读取（B7），用文件路径形态不受影响
