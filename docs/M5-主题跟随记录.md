## 1. 需求与设计

**目标行为**：Hana 宿主主题为深色时，工作区内嵌的 ComfyUI 官方前端用 dark 系色板；宿主浅色时用 light 系色板。宿主主题变化时跟着变，不需要用户手动去 ComfyUI 设置里调。

**实现路径（同源直控，未走中继注入）**：
- 事实依据（本机读码 + 实测）：壳页（`ui/workspace.html`）与内层 iframe（`/_runtime/<rid>/...`）同在宿主域下 → 可访问 `iframe.contentWindow`；ComfyUI 前端 1.53.6 在 GraphCanvas 就绪后把 legacy 实例挂 `window.app`（源码：`GraphCanvas.vue` `window.app = comfyApp`），其 `app.ui.settings.setSettingValue/getSettingValue` 桥接到官方设置链路（`settingStore.set` → 服务端持久化），设置键 `Comfy.ColorPalette` 的变更会触发 `colorPaletteService.loadColorPalette()` 实时换肤。
- 因此无需中继改写响应（D3 预留的"主题注入"未启用）：壳页直接调用内层前端 API 即可，既简单又不改任何中间层。

**切换策略（避免打扰用户自选色板）**：
- 仅当「明暗对立」时切换：宿主 dark ↔ 色板 light 系（或反之）才动手。
- 同明暗不打扰：用户自己选了 nord / solarized 等深色板时，宿主深色下不覆盖；宿主切浅色时才跟随切 light。
- 明暗判定：核心色板集合（dark/nord/solarized/arc/github 深色、light 浅色，核实自前端 v1.53.6 色板 JSON）；自定义色板查其 `light_theme` 字段；未知按"跟随"处理。

**触发时机**：壳页首载（`main()`）、`hana.theme.subscribe` 主题变化、内层 iframe 每次 `load`；就绪等待为 500ms × 48 次轮询（约 24s，覆盖 ComfyUI 前端冷启动）。
