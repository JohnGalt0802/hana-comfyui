## 二、四项落地说明

**① 幂等怎么保证**：两层防重——
- **包裹安装**：模块级哨兵 `historyGroupClickInstalled`，装过即 `return`，`setup()` 重跑（前端对同名扩展生命周期可能执行两遍）不会二次包裹、不会套娃。若 `processMouseDown` 不存在（前端版本差异）只 `console.warn` 跳过，不抛。
- **弹层与样式**：`<style>` 按 id 查重（`historyBarStyleEnsure`，同 `copilotStyleEnsure`）；弹层是**单例**（`historyBarEl`），打开前必拆旧，重复点其他 group = 切换而非叠层。

**② 弹层生命周期**：
- **开**：左键点中 group → `historyBarOpen`，锚定该 group 几何中心下方，打开时才 fetch 一次。
- **关**：三条路径——点 ✕（`stopPropagation` 防透传）；点画布空白（钩子里未命中 group → `historyBarClose`）；点其他 group（拆旧建新，等效切换）。
- **竞态**：`historyBarRequestId` 每次 open/close 递增，在途旧 fetch 响应回来时 reqId 对不上 → 直接丢弃，不会写进新弹层。
- 弹层挂 `document.body`（`position:fixed`），点弹层本体不经过画布 → 不触发 `processMouseDown`，不会自我收起。

**③ fetch 失败路径**：三层兜底，全不抛——
- `fetchApi` 网络异常 / 非 2xx（`resp.ok` false，如端点 404）/ `data.ok !== true` / `resp.json()` 解析失败 → 统一进 catch，弹层内显示红字「提交历史加载失败：HTTP 404 / …」。
- `currentWorkflowInfo()` 抛错 → 回退 `"(未命名)"`。
- 渲染过程中弹层已被关闭/切换（竞态）→ 丢弃，不碰已拆的 DOM。

**④ 坐标与锚定**：点击命中用 `convertEventToCanvasOffset(e)`（官方 API）；锚定反算是它的逆路径：`convertOffsetToCanvas`（同单位，CSS px，不乘 DPR）+ 画布 `getBoundingClientRect`；两步都有 try/catch / 兜底式（`ds.scale/offset` 手写逆变换；anchor 取不到回退视口中心），任何一步失败弹层仍能打开。
