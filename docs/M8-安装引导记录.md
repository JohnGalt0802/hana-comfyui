# M8 · 安装引导（选位置 + 发起安装）记录

**日期**：2026-09-22
**版本**：v0.4.0 → v0.5.0
**需求**：用户点「小花帮你装」后显示"选择安装目录"按钮，选定位置写进提示词交给助手安装；
形态定为「候选盘快选 + 自定义目录」双轨。

## 实现

| 层 | 改动 |
|---|---|
| 中继 | `GET /_relay/drives`（各盘剩余空间/可写性/系统盘 + 推荐 `<盘>:\ComfyUI`）、`GET/POST /_relay/custom-roots`（App 推送自定义位置，探测优先检查；POST 需 controlKey）、`GET /_relay/env`（环境诊断）；`detectInstall` 增加"外层布局"识别（`<位置>\ComfyUI` + 兄弟 `venv`）|
| app | 路由 `install-targets`（候选）、`install-target`（存/清自定义位置 → app-data/install-target.json，并推送中继）、`install-prompt`（提示词模板，后端单点维护）、`install-launch`（`sdk.sessions.create({})` + `sdk.sessions.send` 在默认工作区建会话投递提示词）；中继重启（pid 变化）自动重推自定义位置 |
| UI | 工作区弹窗三步：①选方式（助手装/自己装/稍后）②选位置（候选盘带剩余空间与推荐 + 「自定义目录…」走 `hana.resources.pick`）→ 动作（直接发起安装 / 复制安装指令）③完成提示；顶栏常驻「安装引导」入口；每浏览器自动弹一次 |
| manifest | 新增能力 `app/resources.read`（目录选择器账本词）——经用户审查批准后生效 |

## 修复（本轮实测暴露）

**受管 runtime 的 `os.homedir()` 被宿主重写**为 `app-data/<app>/.runtime-tmp`，导致：
- 探测的「用户目录」候选（`~/ComfyUI`、`~/Desktop/ComfyUI`、`~/Documents/ComfyUI`）全部失效；
- 候选盘列表里出现 `C:\Users\...\app-data\comfyui-hana\.runtime-tmp\ComfyUI` 这种错误项。

**修复**：`realHome()` 多来源回退（USERPROFILE → HOMEDRIVE+HOMEPATH → homedir() → HOME），排除含 `app-data` / `.runtime-tmp` 的污染路径，并做存在性校验。修复后候选正确显示 `C:\Users\John Galt\ComfyUI`。
**影响面**：分发给"把 ComfyUI 装在用户目录"的用户时，这是"装完扫不到"的隐患；此修复同样让 `--probe-env` 更准。
