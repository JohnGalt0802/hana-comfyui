## 二、机制坐实（读源码，非推断）

**ComfySwitchNode**（`comfy_extras/nodes_logic.py` class SwitchNode）：
```python
check_lazy_status(cls, switch, on_false=MISSING, on_true=MISSING):
    if switch and on_true is None: return ["on_true"]
    if not switch and on_false is None: return ["on_false"]
```
`lazy=True` → **未选中分支不求值**。故 OFF 时放大链**整条不执行**（生图零耗时变化）。

**执行链推演**：
- OFF：`#30` 取 on_false=#24 → 只跑生图链 ✅
- ON+链式(#31=false)：`#30` 取 on_true=#41 → #41←#40←#36←#35←#34←#32←(on_false)#24 → 先算生图再放大，**无环** ✅
- ON+选图(#31=true)：`#32` 取 on_true=#33 → 直接放大所选图 ✅
