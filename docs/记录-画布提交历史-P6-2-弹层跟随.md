## 2. 跟随机制说明

### 2.1 rAF 启停时机
- **开**：`historyBarOpen(group)` 末尾（`document.body.appendChild(bar)` 之后）调 `historyBarFollowStart()`。
  - `historyBarFollowStart` 内部**先 `historyBarFollowStop()`** 停旧循环（切换框/存档后重开时防叠加），再立即 `historyBarFollowApply()` 落首帧（避免首帧错位），最后 `requestAnimationFrame(historyBarFollowTick)` 续帧。
- **停**：`historyBarClose()` 里 `historyBarFollowStop()`；另外 `historyBarFollowTick` 每帧开头 `if (!bar || !bar.isConnected) { historyBarFollowStop(); return; }` —— 弹层被移除（含非经 `historyBarClose` 的移除）也不留悬挂 rAF。
- **只在打开时跑**：关闭后无循环；`historyBarReopen`（存档后刷新）经 `historyBarOpen` 走同一启停路径。

### 2.2 变了才更新（避免无谓重排）
- `historyBarFollowApply` 读 `app.canvas.ds.scale` / `ds.offset`，与 `historyBarFollowPrev` 逐字段比对；**三者全等 → 直接 `return`（不写任何 style）**，只有变化才进入写入分支。
- 视图态未变时循环体只做「读 + 比 + 续帧」，不触发布局/重绘；无画布或 `ds` 缺失时返回 false（不写 style，不报错）。

### 2.3 transform 写法
```
bar.style.transformOrigin = "50% 100%";                    // 变形原点 = 底边中心（对准框顶）
bar.style.transform = "translate(-50%, -100%) scale(k)";   // translate 对齐 + 整体缩放
bar.style.left = <锚点 x>px;                                // left/top 直接给框顶中心屏幕坐标
bar.style.top  = <锚点 y>px;
```
- `translate(-50%, -100%)` 已把弹层底边中心对齐到 `left/top`，故锚点直接取框顶中心（`historyGroupTopScreen(historyBarGroup)`），**不需要**再减 `bh`。
- `#hana-history-bar` 仍是 `position:fixed`；`transform` 不参与布局，`left/top` 与 transform 叠加安全。
- 取不到框 → 锚点回退视口中心（`innerWidth/2`, `innerHeight/2`），与旧行为一致。

### 2.4 缩放与下限保护
- `k = clamp(ds.scale, 0.55, 1.6)`（`HISTORY_BAR_MIN_SCALE` / `HISTORY_BAR_MAX_SCALE`）。
- **zoom out**：`ds.scale` 到 0.05 时弹层只缩到 `0.55`，不缩没，保证文字可读（下限）。
- **zoom in**：`ds.scale` 超过 1.6 时弹层封顶 1.6，避免放大到遮挡画布（上限）。

### 2.5 水平钳制
- 跟随模式**按缩放后的可视宽度**钳制：取 `offsetWidth * k` 作 `bw` 传入既有 `historyBarClampLeft(left, bw)`（该函数按画布元素左右边界 + 视口 8px 兜底），结果再换算回锚点 x（`+ visW / 2`）。
- 保持「不跑出画布」；画布比弹层还窄时沿用 `historyBarClampLeft` 原退化路径（贴画布左边，右侧可能溢出，见 §5 存疑项）。

### 2.6 弹层内绝对定位元素（气泡）的补偿
- 弹层带 `scale(k)` 后，其内部 `.hhb-bubble`（`position:absolute`）用 `getBoundingClientRect` 差值定位时，差值已含 k，直接写回本地坐标会被**二次缩放**。
- `historyBarBubbleShow` 定位段改为：`(屏幕差值) / k - 目标尺寸/2`，并用 `barW = offsetWidth`（布局宽度，非缩放后）做水平钳制上界、用 `bh * k` 做视口越界判据。
- 缩略图浮层 `.hhb-shots` 是**文档流内**元素（非绝对定位），随弹层一起缩放，无需单独补偿。
