## 8. 约束（务必遵守）

1. **`node --check` 是假绿（踩坑 #42，2026-10-12）**：桥顶部含 `import`，Node 走 ESM 路径解析 → 重复声明/语法错不报、`exit 0` 假绿；浏览器按经典脚本加载才暴露（`Identifier already declared` → 整桥不执行）。校验必须用 `node tools/check-bridge-syntax.mjs <file>`（剥 import 后 `new Function(src)` 等价浏览器加载，抓重复声明/语法错）。见 `docs/踩坑记录.md` L716–728。
2. **桥内 CSS 在 JS 模板串里**：所有 CSS 以反引号模板串内联（如 L344/L2574/L3298/L4514）。注释**只能 `/* */`**，**不能 `//`**——JS 字符串内的 `//` 会变成 CSS/文本字符而非注释，破坏样式或引发行尾杂质。
3. **`app/lib/commit-graph-lanes.mjs` 与桥内联版逐逻辑一致**：桥因 CSP 不能 import ESM，泳道算法在桥内内联为 `commitGraphLanes()`（L4663，注释明确“逻辑与 app/lib/commit-graph-lanes.mjs 逐条一致”“严禁改为 import”）。改 `commit-graph-lanes.mjs` 时**必须同步本文件内联版**（两处逻辑逐条对齐），否则树（L4732 调 `commitGraphLanes`）与后端/侧栏泳道不一致。
4. **编辑长文件锚点要足**：#42 根因之一是重复粘贴（锚点不足），`edit` 的 `oldText` 需含足量上下唯一上下文，避免歧义粘贴。
5. **只读验证也要防写**（踩坑 #43）：任何 headless 验证夹具默认拦一切非 GET，桥/后端均不得在只读普查下被写；本普查未跑任何浏览器/命令改动。
