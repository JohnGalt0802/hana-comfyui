4. **app 优先**：新需求先答"hui app 内能否实现"；只有画布内 UI 这类 app 结构上够不到的，才动 CUI 插件；
5. **留口子**：架构预留扩展位（如 copilot `level`、skill 主题位），不把将来的路堵死。
