# 方案 · 提交树 hover 预览一律向上（2026-10-14）

> **需求**（John 2026-10-14 凌晨，附截图）：提交树里鼠标停留节点的预览信息（`#018 · 10-14 01:51` 那张气泡）出现在**节点下方**，被面板底边**遮挡**；要改成**向上显示**。

---

## 1. 问题定位

**病灶函数**：`app/bridge/js/hana-bridge-<tag>.js` 里的 `historyTreeBubbleShow(tick, ent)`（约 L5410-5444）。
落位段（约 L5435-5437）：

```js
// 树贴底：默认气泡在刻度上方；上方放不下 → 落刻度下方（树面板内部兜底）
let top = tr.top - rr.top - bh - 6;        // 默认向上
if (top < 4) top = tr.bottom - rr.top + 6; // ← 无条件落下方
```

**为什么必被裁**：树容器 `#hana-history-tree` 是**贴底**定位（`position:absolute; left:0; right:0; bottom:0`）。"落刻度下方" = 往屏幕底边外面去（节点已在容器底部附近），气泡的下半截直接出视口/被面板底边压住。截图正是这个形态。

**对照（同类浮层，均已正确）**：
- `historyBarBubbleShow`（横轴 hover 气泡，约 L3769）：落下方有**条件**——`tr.top - bh*k - 6 < 4 && tr.bottom + 6 + bh*k < window.innerHeight - 4`（上方真放不下**且**下方真放得下才落，且用 `window.innerHeight` 按屏幕判）。**不会遮挡**。
- `historyTreeShotsToggle`（树缩略图浮层，约 L5489）：2026-10-13 第2a 已改「**永远在被点节点上方**（去掉越顶→落下方分支）」（L5539 注释）。
- `historyBarShotsToggle`（横轴缩略图浮层）：同上，永远向上。

结论：**只有树 hover 气泡这一处**还留着"无条件落下方"的旧逻辑。

---

## 2. 修法（最小改动）

`historyTreeBubbleShow` 的落位：**去掉「落下方」分支，一律向上**。

```js
// 树贴底：气泡一律向上（下方必出视口/被裁）；向上溢出不裁（树容器 overflow visible，
// 气泡显示在容器上方的画布区，仍可见）。仅水平仍钳在容器内。
let top = tr.top - rr.top - bh - 6;
```

- **水平**：保留原钳制（`left` 限在容器内）不变。
- **垂直**：不再有"落下方"分支。上方放不下时气泡向上溢出容器顶——树容器 `#hana-history-tree` **无 overflow 设置**（默认 `visible`），不会裁剪，气泡显示在容器上方的画布区域。
- **注释与 CSS 注释同步**：把 `.htr-bubble` 附近"（越界落到刻度下方）"类旧注释一并更正（若存在）。

**不改**：`historyBarBubbleShow`（横轴，已有智能自适应，改了反而可能在屏幕顶被裁，属倒退）、两处缩略图浮层（已向上）。
