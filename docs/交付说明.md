# Hana-ComfyUI 交付说明（v0.9）

> 回答四个问题：这是什么、怎么用、现在什么状态、还剩什么。

## 一句话

把本机 ComfyUI 接进 Hana：界面是 ComfyUI 官方前端（零改造嵌入），能力上 Agent 可以直接提交、跟踪、取回生成任务（工具面 + 任务卡 + 产物回执）；v0.9 起还能直接读/改你正在看的同一张画布（投影 / 体检 / 追踪 / 大纲 / patch 事务 / 自动排布）。

## 怎么用

### 1. 界面（人用）

- **打开**：Hana 导航 →「ComfyUI 工作区」（整页卡，可拆窗）。
- **实质**：宿主内嵌官方前端，经受管中继代理到 `127.0.0.1:8188`（HTTP/WS 全通）；ComfyUI 原生界面功能都在。
- **前提**：ComfyUI 服务在跑（你现有的启动方式即可；v1 是 attach 模式，暂不接管进程托管）。

### 2. Agent 调度（Agent 用）

- **重要**：请**开新对话**使用。会话的工具清单是创建时的快照，旧对话看不到新装的工具。
- 说人话即可，例如："用 ComfyUI 生成一张测试图"、"看看 ComfyUI 队列里有什么"、"把刚才那张图取回来"。
- 工具（`comfyui`，10 个动作）：`status` / `submit` / `query` / `result` / `cancel` / `workflows` / `upload` / `service` / `update` / `canvas`。
- 每次生成 = 一条正式宿主任务（后台进程可见）+ 一张任务卡（进度/产物）+ 完成后 next-step 回执（桌面会话）。

### 3. 已知边界（诚实清单）

- **回执投递**：宿主只对"桌面会话"投递 next-step 回执；子代理会话提交时工具会明确标注"不会自动回执，请用 query/result 主动取"（工具文案已处理）。
- **服务模式**：v1 为 attach 外部实例（不接管拉起/停止；托管模式在路线图）。
- **整页卡视觉**：待你首次打开确认。
- **宿主侧**：有一条早期测试任务记录在静默重试（无副作用）；如需清理可出方案。
