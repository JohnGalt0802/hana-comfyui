# 施工：差分放大改「像素放大 + 目标分辨率重建」（B 方案）

**来源**：John 2026-10-13 晚 —— 诊断「差分放大发糊」后选 **B（像素空间放大重建）** + 改完重跑验证。
**依据**：`docs/排查-差分放大产物发糊-20261013.md`

## 一、原链（发糊的那条）
```
#32 源图(switch) → #34 VAEEncode → #35 LatentUpscaleBy(×2,bislerp) → #36 SetLatentNoiseMask(←#37 mask=0.3)
   → #40 采样(guider #39←#38 差分 strength=0.1, sigmas #22, sampler #21, noise #20) → #41 VAEDecode → #30.on_true
```
**两个致糊点**：① latent 空间插值放大（信息贫乏）；② mask 0.3 + strength 0.1 → 加大面积不重绘。

## 二、新链（B）
```
#32 源图 → #43 ImageScaleBy(lanczos ×2)   ← 【像素放大】
          → #34 VAEEncode
          → #36 SetLatentNoiseMask(← #37 mask=1.0)   ← 全图参与
          → #40 采样(sigmas ← #42 新调度器 denoise=0.45, steps=12, karras)
          → #41 VAEDecode（已是目标分辨率）
          → #30.on_true
```
**要点**：放大在**像素空间**（lanczos，干净），重建在**目标分辨率**（模型补 2× 细节），mask=1（全图重绘），独立调度器 denoise=0.45（重建而非重画）。

## 三、改动清单
| # | 动作 |
|---|---|
| 新增 `#42` | BasicScheduler「⑦ 放大·调度器」：karras / 12 步 / **denoise=0.45** |
| 新增 `#43` | ImageScaleBy「⑧ 像素放大 ×2（lanczos）」：lanczos / **2.0** |
| 接线 | `#32 → #43.image`；`#43 → #34.pixels`（替代 #32 直连）；`#34 → #36.samples`（**绕过 #35**）；`#42.model ← #26`；`#42 → #40.sigmas`（替代 #22） |
| 参数 | `#37 SolidMask.value` 0.3 → **1.0** |
| 旁路 | `#35 LatentUpscaleBy` 悬空（保留可回退，不删） |

## 四、本机限制（如实）
- **无放大模型**（`upscale_models` 空）→ 像素放大只能是 lanczos 插值，**不能走 ESRGAN/Foolhardy**。
- 故本方案上限 =「清晰图的 2× 插值 + 目标分辨率重建补细节」；比原链强，但不及专用放大模型。
- **更进一步**（可选，待 John）：装 1 个放大模型（如 4x-UltraSharp / RealESRGAN）→ 像素放大换 `UpscaleModelLoader+ImageUpscaleWithModel`，质量再上一档。
