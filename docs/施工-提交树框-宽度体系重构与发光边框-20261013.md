# 施工：提交树/框 · 宽度体系重构 + 发光边框（2026-10-13 凌晨）

**来源**：John 三条（2026-10-13 02:4x）：
1. 提交树节点再窄些、提交历史框节点再宽些；
2. 两者「单提交块 vs 多提交块」宽度差拉大，**单块更瘦**；
3. 提交历史框（及树）边框**改发光，不要实色**。
**John 定调（关键）**：「**不用考虑物理空间，面板可以滚动**」——colW 不得为装下全部节点而压缩。

---

## 根因（上一版为何差异消失）

`colW = min(72, max(11, availW/n))`：60 节点时 colW≈11.7px →
- 单块 `tw = colW*0.72 ≈ 8.4px`，多块 `min(tw+8, colW-2)=9.7px` → **差仅 1.3px，肉眼分不出**。
- 上一版为「防重叠」加的 `clamp(…, colW-2)`，在密档把多块压到几乎没宽 → **反而抹平差异**。

**新口径**：面板横向可滚（`.hhb-axis`/`.tcanvas` 均 `overflow-x:auto`）→ **colW 设足够的下限，n 大时溢出滚动，不压缩**。

---

## 规格

### 1. colW 下限抬高（不压缩，靠滚动）
- 框：`colW = Math.min(72, Math.max(22, availW / n))`（下限 11 → **22**）
- 树：`colW = Math.max(16, Math.min(56, (availW - 24) / n))`（下限 9 → **16**）

### 2. 单块更瘦 / 多块更宽（差异拉大）
- 框单块：`tw = Math.min(24, Math.max(5, colW * 0.5))`（系数 0.72 → **0.5**）
- 框多块：`twBulge = Math.min(tw + 10, colW - 3)`（+8 → **+10**）
- 树单块：`nw = Math.max(5, Math.min(colW - 3, colW * 0.45))`（系数 0.55 → **0.45**）
- 树多块：`nwBulge = Math.min(nw + 10, colW - 3)`（+8 → **+10**）
- **目标：单/多差 ≥ 6px（密档也要达到）**，`gap ≥ 2px` 不粘连。

### 3. 边框改发光（不要实色）
现状：`border: 2px solid var(--hhb-c)` + 弱外光晕 → 观感是「实心框」。
改为「发光描边」：
- border-color 半透明：`color-mix(in oklab, var(--hhb-c) 60%, transparent)`（树用 `--htr-c`）
- 外光晕加强：`box-shadow: …, 0 0 10px color-mix(in oklab, var(--hhb-c) 65%, transparent)`
- 合并（bulge）保持略强于单次（border 2.5px / 光晕更亮）。
- **框与树同口径**。

## 验收
- 各档数值表：n = 10 / 30 / 60 / 150 下，框单/框多/树单/树多 + gap；确认 **单/多差 ≥ 6px、gap ≥ 2**。
- 边框 computed：border-color 为半透明（`color-mix` 生效）、外光晕可见。
- PARSE OK（`tools/check-bridge-syntax.mjs`）。
- 部署：桥 js 免重启，重载工作区页面即生效。
