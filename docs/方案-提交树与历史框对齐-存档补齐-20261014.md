# 方案 · 提交树与提交历史框进一步对齐（缩略图统一 + 树补存档）（2026-10-14）

> **需求**（John 2026-10-14）：
> 1. 多图预览还是小（单图已放大）→ 多缩略图与**树单图缩略图**大小对齐；
> 2. 提交树与提交历史框**进一步对齐**（两视图一致性）；
> 3. 提交树**缺「保存当前画布」**功能（弹层有，树没有）；
> 4. 二者缩略图都跟**提交树的单图缩略图**大小对齐；
> 5. 多缩略图预览**保留三张图宽度**，其余滚轮左右滚动。

## 1. 现状（已读代码坐实）

| 项 | 提交历史框（弹层 `.hhb-*`） | 提交树（`.htr-*`） |
|---|---|---|
| 浮层容器 max-width | `min(560px, 88vw)`（L3014） | `min(760px, 92vw)`（L5015） |
| 单图 | `max-width:520px; max-height:220px`（L3030） | **`max-width:720px; max-height:340px`（L5028）** ← 基准 |
| 多图 | `height:58px`（L3031） | `height:84px`（L5029） |
| 「存档当前画布」按钮 | ✅ 有（`.hhb-save`，`historySaveClick`） | ❌ 无 |
| 「回到这一版」 | ✅ 有（`.hhb-roll`） | ⚠️ 仅双击节点间接触发 |

**基准**：John 指定「树单图缩略图」（**720×340**）为两视图统一目标。

**两处结构性依赖**：
- 弹层浮层 `max-width:560px` < 三张图所需宽度 → 多图三张并排在弹层放不下，须放大到与树一致（760）。
- `historySaveClick` 首行 `if (!historyBarEl || historySaveBusy) return;` → **硬绑弹层**，树无弹层时无法存档。

## 2. 改动（均在桥 js；同一主题，一次改完一次部署）

### 2.1 缩略图尺寸统一到「树单图」基准（两视图）

| 类 | 改后 |
|---|---|
| 树单图 `.htr-shots-img.single` | `width:100%; max-width:720px; height:auto; max-height:340px; object-fit:contain`（**不变**，即基准） |
| 树多图 `.htr-shots-img.multi` | `width:240px; height:auto; max-height:340px; object-fit:contain; flex:none`（原 `height:84px`） |
| 弹层单图 `.hhb-shots .hhb-thumb-img.single` | `max-width:720px; max-height:340px`（原 520×220） |
| 弹层多图 `.hhb-shots .hhb-thumb-img.multi` | `width:240px; height:auto; max-height:340px; object-fit:contain; flex:none`（原 `height:58px`） |

### 2.2 浮层容器宽度统一

- 弹层 `.hhb-shots { max-width: min(760px, 92vw); }`（原 560）→ 与树一致，使三张图能并排。

### 2.3 多图「保留三张宽度 + 横滚」

两视图的多图浮层：每张 `width:240px`，strip 为 `flex nowrap + overflow-x:auto`（**已有**）。
- `240×3 + gap(4px)×2 = 728px`；加浮层左右 padding(10×2)=20 → `748px` < `max-width:760px` → **三张并排完整可见**；
- 第 4 张起 strip 内容宽 > 容器 → **滚轮左右滚**（`wheel` 处理**已有**，两视图均实现，无需新增）。
- 2 张时浮层按内容收窄（absolute shrink-to-fit），不留空位。

### 2.4 提交树补「存档当前画布」（核心功能补齐）

**(a) `historySaveClick` 解耦弹层**（对齐 `historyRollbackExecute` 的两容器口径）：
```js
// 改前
if (!historyBarEl || historySaveBusy) return;
const btn = historyBarEl.querySelector(".hhb-save");
// 改后
if ((!historyBarEl && !historyTreeEl) || historySaveBusy) return;
const btn = historyBarEl ? historyBarEl.querySelector(".hhb-save") : null;
```
- 提示（`historyBarTip` 只在弹层内）：弹层不在时改用 `historyRollbackToast(msg, true)` 报错（该函数已支持 isError）。
- 成功刷新：弹层在 → `historyBarReopen()`；否则 → `historyTreeRefresh()`。
- 成功提示 `historyRollbackToast("已存档 #NNN")` **不变**（本来就挂 body）。

**(b) 树注入「存档当前画布」按钮**：
在 `historyTreeEnsure()` 的**收纳条** `collapsed` 内（`sum`/`count` 之后、`toggle` 之前或之后）加一个按钮：
- 类 `htr-save-btn`，文案「存档当前画布」，样式仿 `.hhb-save`（浅灰底 + 描边 + 圆角），但不占满宽。
- 点击：`ev.stopPropagation()`（防冒泡触发收纳条展开/收起）+ `void historySaveClick()`。
- 存档成功后树刷新（见 (a)）。

**(c) 树样式**：新增 `.htr-save-btn` CSS（同 `.hhb-save` 观感：`background:rgba(255,255,255,.07); border:1px solid rgba(255,255,255,.24); color:#dfe7ef; border-radius:7px; padding:2px 10px; font-size:11px; cursor:pointer;`）。

1. **弹层**（提交历史框）：单击刻度带图 → 单图明显更大（720×340）；多图每张与树一致（236 宽）、**三张并排**、第 4 张起横滚。

4. 两视图缩略图**视觉一致**（同一张图在两处显示大小相同）。
