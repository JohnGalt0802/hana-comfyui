# hui 收录包（暂名）— 构想与 v0 骨架

日期：2026-09-27
状态：**构想**（未实施，待拍板）
上游：用户指出「app 不强制捆绑 skill 和 cui 侧插件；可以创建一个收录包收录我们认为有价值的插件和 Skill，包独立于 app 本体，用户根据需要自行选择拉取安装或不安装」

---

## 1. 原则

- **app 本体零捆绑**：hui 的交付物（app 包）不带任何第三方插件、第三方 skill；app 只管通道与自身能力。
- **收录包独立**：独立版本、独立仓库、独立生命周期；app 不知道它也能活，知道它更顺。
- **用户显式选择**：默认不装；单项可装 / 可不装 / 可卸，每次动作可追溯。
- **优先上游直取**：收录 = 记录上游坐标 + 安装脚本（从上游拉），不镜像代码（版权与更新都干净）。

## 2. 形态（v0 骨架，建议）

独立仓库（名字待定，候选：`hana-comfyui-collection` / `hui-extras` / `cui-collection`）：

```
README.md            # 人读：有什么、怎么装、怎么卸
index.json           # 机器读清单（对齐 skills-packs 的 JSON 风格）
plugins/<name>/      # cui 侧插件条目：install.ps1 + 说明 + 上游坐标 + 卸载
skills/<name>/       # skill 条目：来源 + 安装落点 + 卸载
tools/list.ps1       # 列出已装 / 未装状态
```

**三类消费者**：

1. 用户手动（按 README 装）；
2. hui 里的 agent（"把 XX 装上" → 读 index.json → 跑脚本）；
3. 远期可选：app 设置页「收录」页签（只读清单 + 一键装 / 卸；**不是 v0 必需**）。

**安装落点**：

- cui 插件 → `D:\ComfyUI\ComfyUI\custom_nodes\<name>`
- skill → `%HANA_HOME%\skills\<name>`（或指定 agent 的技能目录）

## 4. 与 app 的关系

- app **不做**：捆绑、预装、隐藏依赖收录内容。
- app **未来可选做**：设置页 / 工作区一个"收录"入口（只读 index.json 渲染 + 调脚本）——数据源独立，app 只提供机制。
- 边界：收录包坏了不影响 app；app 升级不牵动收录包。

## 4.5 口径更新（2026-09-27 晚，用户明确）
