## 1. 浮层交互矩阵（全面清点，标缺口）

桥内与提交历史相关的浮层共 6 个，逐一列开/关途径：

| # | 浮层 | 元素/ID | 现有关闭途径 | 缺口 |
|---|---|---|---|---|
| 1 | 树 hover 气泡 | `.htr-bubble` | mouseleave | ✅ 无需点关（hover 语义） |
| 2 | 树缩略图预览 | `.htr-shots` | 再点同节点；点别的节点；重渲染 | ❌ **点外部不关** |
| 3 | 弹层 hover 气泡 | `.hhb-bubble` | mouseleave | ✅ 无需点关 |
| 4 | 弹层缩略图预览 | `.hhb-shots` | 再点同刻度；点别的刻度；弹层收起 | ❌ **点外部不关** |
| 5 | 回跳确认框 | `#hana-history-bar-confirm` | 「取消」「回跳」按钮 | ❌ **无 Esc；点外部不关** |
| 6 | 全屏看原图 lightbox | `#hana-history-lightbox` | 点任意处；Esc；✕ | ✅ 齐 |

**缺口三项**：② 树预览、④ 弹层预览、⑤ 确认框——均**点画布/外部空白不关**；确认框还缺 **Esc**。

## 2. 修法

### 2.1 通用「点外部关闭」工具（一次写好，三处共用）

在桥内新增一个小工具，统一口径：

```js
// 点「浮层之外」时执行 onOutside（用于：预览浮层 / 确认框 点击外部关闭）。
// 口径：pointerdown 的 target 不在浮层元素内，也不在其触发区（节点/刻度）内 → 视为「点外部」。
// 用 pointerdown（早于 click）：关闭先发生，随后节点自身的 click 再决定「切换/重开」，不互相打架。
// 返回解绑函数（浮层关闭时调用，避免监听堆积）。
function bindOutsideClose(floats, onOutside) {
  const els = (Array.isArray(floats) ? floats : [floats]).filter(Boolean);
  const handler = (ev) => {
    const t = ev && ev.target;
    if (!t) return;
    for (const el of els) if (el && el.contains(t)) return;   // 点在浮层内 → 不关
    try { onOutside(); } catch { /* 关闭失败不影响主流程 */ }
  };
  document.addEventListener("pointerdown", handler, true);      // 捕获阶段：先于任何业务 click
  return () => document.removeEventListener("pointerdown", handler, true);
}
```

**关键判定**：只在「点浮层之外」触发。点**节点/刻度本身**属于"触发区"——但那个由节点自己的 click 处理（再点同节点=关、点别的=切换），所以：

- **树预览**：绑定 `floats = [box]`，`onOutside = historyTreeShotsHide`。但要注意**不能**因"点另一个节点"而误判——点节点时 `target` 在节点内、不在 `box` 内 → 会触发 `onOutside`（关闭）→ 随后节点 click 又按 toggle 逻辑开新的 → **视觉结果是切换** ✅（与现行为一致）。点**同一节点**：`onOutside` 先关，节点 click 再 toggle（此时 `historyTreeShotsTick === tick` 已被清 → 判定"非同一"→ **重新打开**）→ 行为反转成"关了又开"。**这是必须避免的**。

  → **修正**：`floats` 传入时**加上该浮层的触发元素集合排除**不可行（触发元素是动态的）。改口径：**「点外部」= target 不在浮层内 且 不在树容器 `historyTreeEl` 内**。
  - 点树容器内任何处（含其它节点、面板空白）→ **不关**（交给节点 click 的既有 toggle/切换逻辑）；
  - 点树容器**之外**（画布空白、页面其它地方）→ **关**。

  这样"再点同节点=关 / 点别的=切换 / 点画布空白=关"三者互不冲突。

  树预览：`bindOutsideClose` 的判定域改为「`historyTreeEl` 容器」。
  弹层预览：同理，判定域为「`historyBarEl` 容器」（点弹层内任何处不关，交给刻度逻辑；点弹层外=关）。

  故工具签名调整为：
  ```js
  function bindOutsideClose(container, onOutside) { ... }  // target 在 container 内 → 不关；否则关
  ```

### 2.2 树预览：点外部关

`historyTreeShotsToggle` 打开浮层后：
```js
const off = bindOutsideClose(historyTreeEl, () => historyTreeShotsHide());
box.__offOutside = off;   // 存储解绑
```
`historyTreeShotsHide` 里调用 `box.__offOutside?.()` 解绑（幂等；box 被移除时也解绑）。

（"再点同节点=关"仍由 `historyTreeNodeClick` 的 toggle 负责；点外部关由本工具负责；两者判定域不重叠。）

### 2.3 弹层预览：点外部关

同 2.2，容器 = `historyBarEl`，`onOutside = historyBarShotsHide`。

### 2.4 确认框：点外部关 + Esc 关

`historyRollbackConfirmOpen`：
- `bindOutsideClose(document.body /* 即"任何非确认框处" */, () => historyRollbackConfirmClose())`。
  - 但确认框可能由**树**或**弹层**触发；点树/弹层内的其它节点不应关确认框？——**应关**（换选即复位）。故此处置**判定域为空**：只要 target 不在确认框 `box` 内 → 关。
  - 实现：`bindOutsideClose(box, close)` 用**排除式**（target 在 box 内则不关，否则关）。为此工具需支持"只传浮层自身"的形态：`container` 传浮层自身即得此语义。**所以工具统一为：target 在 container 内→不关；否则关**。树/弹层传各自**宿主容器**、确认框传**自身**。
- Esc：给确认框加 keydown 监听（document），Esc → `historyRollbackConfirmClose`；关闭时解绑。

## 5. 验收标准

1. 树里打开某节点预览 → **点画布空白处**，预览关闭。
2. 弹层里打开某刻度预览 → **点弹层外**，预览关闭。
3. 回跳确认框 → **点外部**或按 **Esc** 关闭；点「取消」「回跳」行为不变。
4. 既有：再点同节点=关、点别的节点=切换、双击=回跳 —— **不回归**。
5. 反复开关多次，无监听堆积（关闭即解绑）。
