## 第 1 条 · 「重载工作区」按钮移入宿主左侧栏

**现状**：按钮 `#ws-bar-reload`（`app/ui/workspace.html`）悬浮在画布 `#ws-body` **右上角**（`right:10px; top:8px`），点击调 `requestFrameReload("manual")` 重载内层 ComfyUI iframe。
**目标**：移入 hui 宿主左侧栏 = `contributes.cards[0].functionPanel`（id `status`，route `/panel.html`），与「启动/停止服务」「重启中继」并列。

**难点（跨页）**：`panel.html` 与 `workspace.html` 是**两个页面实例**，panel 无法直接操作 workspace 的内层 iframe。需要通道：
- 方案（推荐）：`app/index.js` 增一条路由（如 `POST /comfyui-hana/shell/reload`）→ 把 `{op:"frame.reload"}` 推入现有 `shellBridge.queue` → 工作区壳页的 `/comfyui-hana/shell/poll` 轮询到并执行。
- 复用既有：`shellBridge`（index.js L2086 起）、壳页 `shellTick()` 轮询（workspace.js）、`frame.reload` op（workspace.js L1429）。
- panel 侧：新增按钮调该路由；注意 panel 是 functionPanel（与 workspace 壳页是否同源、凭据如何——实现时核实）。
- workspace 侧：`#ws-bar-reload` 悬浮按钮**移除**（保留 `requestFrameReload` 函数本身，供 op 调用）。

**验收**：宿主左侧栏出现「重载工作区」按钮；点击后工作区内层 ComfyUI iframe 重载（等价 Ctrl+R，草稿自动恢复）；画布右上角不再有该悬浮按钮。
