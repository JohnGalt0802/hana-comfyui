## A. 待用户（人工验收，2 项）

### A1. 整页卡视觉确认（V6）
- **做什么**：在 Hana 桌面打开 Card Center → 打开「ComfyUI 工作区」整页卡。
- **判定**：ComfyUI 官方界面完整渲染（节点图/队列/面板），可正常交互（拖动节点、打开设置、队列可见）。
- **备注**：M0 受会话工具限制未能程序化打开真卡；本地已用同款凭据链路验证过渲染与缩略图（M0 §8 / M2 §4），此步只差"真·整页卡"眼见为实。
- **可选留档**：`card_screenshot`（卡打开后由 agent 截图）或手动截图放 `docs/m2-results/`。

### A2. 桌面会话回执终极验证（next-step 全链路）
- **背景**：M2 终验的任务发自**子代理会话**，被宿主投递边界拦下（诊断见 `docs/M2-验证记录.md` §10）；**桌面会话**路径有 hana-downloader 76 条成功先例，但本 App 尚缺一条实测。
- **做什么**：在**主对话**（非子代理）让 Agent 提交一次极小任务，例如：
  ```
  comfyui(action="submit",
    workflow={"1":{"class_type":"EmptyImage","inputs":{"width":64,"height":64,"batch_size":1,"color":0}},
              "2":{"class_type":"SaveImage","inputs":{"images":["1",0],"filename_prefix":"comfyui_hana_receipt"}}},
    clientLabel="回执终验")
  ```
- **判定**：
  1. 提交后在**下一个输入点**收到回执（含产物路径）——不打断在途回合；
  2. `comfyui(action="query", taskId="…")` 的「投递」行显示 `delivered（已送达）`（或结束前为 `published`，下一输入点后转 delivered）；
  3. 「后台进程」中出现该任务且正常终结。

### A3.（可选）官方 smoke 复跑
- 若为本机安装了独立的 Electron 开发运行时：`HANA_APP_ELECTRON=<electron.exe> node <skills>\hana-app-creator\scripts\validate_app.mjs --dir <staging> --smoke --json`。
