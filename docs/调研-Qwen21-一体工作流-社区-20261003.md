## 一句话结论

社区**没有**可直接拿来用的「t2i + 指令级 edit 一键切换」成品工作流；但「单开关切分支」的现成先例存在（foprc 的 t2i＋参考图开关，机制与官方 edit 模板同源），edit 分支内容可参考官方模板与社区两图 edit 工作流——「质量版加 edit 分支」属低成本组装，无需等待现成整包。

## a) 有没有社区做好的「一体式」工作流？

## b) 社区「生成→编辑」的串联实践

**结论：未发现社区"同图内生成→读回→编辑"的成品案例**；通行做法分四层：

- **同图 latent 直切（不落盘）**：foprc 式开关——参考图经 TextEncodeQwenImage21 产出 latent 后直接把采样起点切过去；官方 edit 模板同机制（ComfySwitchNode 在空 latent 与图像 latent 间切换——本机已确认）。｜[社区说法][官方文档]
- **读 output 目录接回**：核心节点 `LoadImageOutput`（"Load Image (from Outputs)"）从 `ComfyUI/output` 下拉选图＋刷新，把生成图送入 edit。已知坑（官方仓库记录）：参数名带 `[output]` 后缀（issue #8806）；切换工作流后所选图被自动刷新（#9775、#9332）；该节点曾整体损坏、2026-04 修复（PR #13305）。
  - https://github.com/Comfy-Org/ComfyUI/issues/8806 · https://github.com/Comfy-Org/ComfyUI/issues/9775 · https://github.com/Comfy-Org/ComfyUI/pull/13305 ｜[社区说法（官方仓库 issue/PR）]
- **App 级复用**：spark-image-lab「结果→下一次编辑的参考」；2Wild「成品静帧→视频 lane 跨实例链（上传目标实例 input 目录）」。｜[社区说法]
- **官方复用范式**：`background_removal` 模板直接复用 edit 子图＋固定提示词（"Remove the background, and output a PNG image"）——"一个子图多用途"的官方示范。｜[官方文档]
- 附注：模板仓库 commits/issues 检索 `LoadImageOutput`＝0 命中——官方 2.1 模板未用该节点做串联。

## c) edit 输入形态：社区约定与官方说明差异

**提示词引用语法**：官方为 `<image1>`（不带空格；image_1＝被编辑图，其余为内容参考；Qwen 官方 PE 输出 `ratio_follow` 亦用 `<image1>`）｜[官方文档]。社区两种写法并存：zuanfilm 工作流与 Reddit 技巧汇总用 `<image 1>`（带空格）～`<image 10>`；T8mars 用 `<image1>/<image2>`。｜[社区说法]

**多参考图上限**：Qwen 模型口径＝最多 10 张；ComfyUI `TextEncodeQwenImage21` 节点＝16 槽（image_1…image_16），官方两个 edit 模板只接前 10；社区工作流自述 10 张。→ 差异点：**节点容量 16 > 模型/教程口径 10**。｜[官方文档][社区说法]

**分辨率/画布行为**：
- 官方：edit 画布默认继承 image_1——`resolution=0` 保留各参考原像素（取整到 32 倍数）；`resolution>0` 按 resolution² 像素预算缩放 image_1 长宽比；`custom_size` 开则改用 Resolution Selector；超 2K 训练尺寸（如 4K）会掉提示词遵循。｜[官方文档]
- 社区差异/补充（官方说明之外）：foprc——参考模式开启时**刻意绕过宽高比选择器**（尺寸由 TextEncodeQwenImage21 按参考图分辨率决定）；参考图约 1024²、32 倍数；旧版 ComfyUI（<0.37）因空 latent 4ch/64ch 尺寸提示缺失会渲染成双倍尺寸。T8mars——导入图按输出尺寸等比留黑边、不拉伸。zuanfilm——1024² 起步、32 倍数；CFG=1、27 步；用 `QwenImage21Cache` 缓存；GLSL「Nyquist Notch」后处理压网格伪影（社区报 mesh-like noise，建议换 VAE/后处理；HF 已有 texture-fix VAE）。｜[社区说法]
- 采样共性：CFG 恒 1.0（负提示无效）；简单局部编辑 4–8 步可用、整帧 25 步、手部细节约 30+。｜[官方文档]

## 对「质量版加 edit 分支」的借鉴点清单

1. 开关拓扑照抄现成两处：单 Boolean → 两个 Switch（参考图路径＋latent 源），off 时"断路径"；与官方 edit 模板 ComfySwitchNode 同款，全部 core 节点、无新依赖（If/Else Switch 需开 experimental 才能在搜索里找到）。
2. edit 模式绕开 t2i 的 ResolutionSelector，画布交给 image_1/resolution 语义（foprc 明确结论），避免尺寸漂移。
3. 读回生成图：优先 LoadImageOutput（output 直读），注意 [output] 后缀／自动刷新两个坑；或同图 latent 直切不落盘。
4. 保留 Qwen Image 2.1 Cache（KV 前缀缓存）节点（实验性；device auto/gpu/cpu/off、dtype default/int8/int4 档位）。
5. 提示词增强可选挂 PE：PE-T2I 与 PE-I2I 分开选；`refine_prompt`、`thinking_mode` 默认关；留 Preview 检视实际提示词；背景去除类模板不需要。
6. 提示词规范：默认 `<image1>`；多图按序数引用；模板给 10 槽（可扩到 16）。
7. 参数安全带：CFG=1.0 恒定；steps 分 4/25/30+ 三档；负提示无效。
8. 参考图尺寸钳制（32 倍数、约 1024² 或 resolution=0 语义）；大画布代价陡增（12MP≈6s/it vs 1MP≈0.3s/it，官方 docs 引用 RTX 5090 数据）。
9. 透明/RGBA 与去背景：直接复用官方 background_removal 范式（edit 子图＋固定提示词）。
10. 质量增强备选（非必需）：LCS 色调调整、GLSL 去网格伪影、texture-fix VAE。
