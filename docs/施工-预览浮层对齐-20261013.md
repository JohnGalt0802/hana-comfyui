# 施工：预览浮层对齐（树 + 框）（2026-10-13 凌晨）

**来源**：John（2026-10-13 03:0x）三条：
1. 树单张预览图会**往下跑** → 改成预览图**都显示在节点上方**；
2. 提交历史框同样：预览图**出现在上面**；
3. 提交历史框预览**点节点无法关闭**、**点预览图不能左右滚** → 与树**功能对齐**。

**目标**：**框的预览 → 全部对齐树口径**；**树的预览 → 修"越顶落下方"，永远在上方**。

---

## 现状（代码事实）

| 项 | 树 `.htr-shots` | 框 `.hhb-shots`（现状） |
|---|---|---|
| 承载 | **浮层**（`historyTreeEl` 内绝对定位） | **弹层内固定行**（`axisWrap`/`times` 之后的行，非浮层） |

## 规格

### 1. 树浮层：永远在节点上方
`historyTreeShotsToggle` 定位段：去掉「越顶 → 落下方」分支；改为**永远 `top = tr.top - hr.top - bh - 8`**（节点上方）。
- 若上方空间不足（贴到宿主顶），**仍放上方**，允许与画布上缘重叠或溢出（用户要"都在上方"）。
- 水平钳制保留。

### 2. 框预览：从「弹层内固定行」改为「浮在刻度上方」
- 改为**浮层**（挂在弹层内绝对定位，或与树同构挂到外层），定位到**被点刻度的上方**（口径同树）。
- 弹层内原来那行 `.hhb-shots` 的行位**移除**（不再占流），避免弹层跳动。

### 3. 框预览交互对齐树
- **关闭**：改为「**再点同一刻度 → 关；点别的刻度 → 切换**」（同树 `historyTreeShotsTick` 判定）；**移除移出 180ms 自动关**（`historyBarShotsHideSoon` 不再用于此）。
- **横滚**：多图时可滚轮横向滚动（同树）。
- **lightbox 翻页**：点图进全屏传 `{list, index}`（同树），支持左右翻页。

### 4. 统一命名/结构（可选，若低风险）
两处浮层实现趋同（`historyBarShotsToggle` ≈ `historyTreeShotsToggle`）。**不强制合并**，但**行为必须一致**。

## 验收
- 树：任意节点（含最上排）单击 → 浮层**始终在节点上方**；再点同节点关；点别的节点切换；多图可横滚；点图进全屏可左右翻页。
- 框：点刻度 → 浮层在**刻度上方**；再点同一刻度关；点别的刻度切换；多图横滚；点图可翻页。
