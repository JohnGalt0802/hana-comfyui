# 方案：#1 中断自愈与断点恢复（2026-10-13）

**来源**：`docs/汇总-agent-native缺口审视-20261013.md` 第 1 条（读侧+写侧交叉印证的最痛缺口）。
**触发场景**：昨晚真实需求——往画布写 13 个节点，中途目标页被浏览器节流/失联，`no_page` 直接报错，整批中止；agent 不知道做到哪、也无自愈手段。
**性质**：设计（未实现）。不走代码，零风险。

---

## 一、问题拆成两半

| 半 | 现象 | 现状证据 |
|---|---|---|
| **A. 自愈** | 写/读 op 撞到画布短暂不可达（节流 / 页面切换 / 忙）→ 立即抛错，不等待、不重试 | `canvasBridgeInvoke`（`index.js` ~L2134）无等待环；`RETRY_DELAYS_MS`（L50）只服务中继启动 |
| **B. 断点** | 多 patch 序列（如 13 节点分 3 批）中途断 → 无事务 ID / checkpoint，只能靠 `revision/events` 反推 | `writeStack`（桥 L610）= 前端内存、上限 20、重载即清；`patch` 仅**单批**原子回滚（桥 L791 `PATCH_ALLOWED`） |

---

## 二、设计

### A. 自愈：写 op 前置「等画布回来」（带 TTL 短轮询）
- **落点**：`canvasBridgeInvoke` 之上加一个薄包装 `withCanvasRetry(op, args, opts)`，**仅对"可安全重试"的 op 生效**。
- **可安全重试判据**（关键）：
  - **读 op**：天然幂等 → 可重试。
  - **写 op**：**只有"连接层失败"（no_page/no_live_page/offline/timeout，即请求未达前端）可重试**；**"业务层失败"（copilot_off、verify 失败、patch 结果 `ok:false`）绝不重试**（重试=重复改图）。
  - → 判据：`error ∈ {no_page, no_live_page, canvas_offline, timeout}` 且**未见任何前端回执**（区分"没到"与"到了但拒"）。
- **退避**：短序列即可（如 `[2s, 5s, 10s, 20s]`），总时限 ~40s；逾期如实报"画布未回来"。
- **目的对齐**：昨晚的场景正是"等 10 秒页面就回来了"——短轮询即可救。

### B. 断点：patch 序列的 checkpoint
- **落点**：`patch` 每次执行后，返回体增加 `checkpoint`：
  ```json
  { "rev": 182, "fingerprint": "<节点id集哈希>", "applied": ["addNode#29", ...], "at": "..." }
  ```
- **用途**：agent 做多批写时，每批记下 checkpoint；断线后先 `canvas get/revision`，比对 `fingerprint` 判断"第 N 批是否已生效"，**从断点续写**，不重不漏。
- **为什么不做"跨批真事务"**：跨批保持锁会长时间占住画布、影响用户共编；**checkpoint 断言**更轻、也更符合"人机共驾"（一批一批做，每批可见可撤）。
- **可选增强**：`patch` 接受 `expectRev` 参数——若当前 rev ≠ expectRev（说明期间有人改过），拒绝执行并如实报告（防"在变了的地基上接着写"）。

### C. 二者合起来的使用姿势（agent 侧）
```
for 每批 in 分片(edits):
    用 withCanvasRetry 提交该批      # A：短暂掉线自动等
    记录返回的 checkpoint            # B：记下做到哪
# 若中途仍未成功：
    读 revision + fingerprint 比对    # B：判断落点
    从断点续（不重头写）
```

## 三、影响面与风险

| 项 | 说明 |
|---|---|
| 改动文件 | 桥 js（patch 返回 checkpoint、可加 expectRev）+ `app/index.js`（包装重试）。**py 不动。** |
| 风险 | 重试判据若写松 → 可能重复写图。**故判据必须"只见连接层失败才重试"**（本方案核心安全线）。 |
| 兼容 | checkpoint 是**新增字段**，旧调用方忽略即可；`expectRev` 可选，不传行为不变。 |
| 量 | 中（1–2 单） |
