# 施工：出图实时预览（C 档·两级·开关免重启）

**来源**：John 2026-10-13 —— 问题「生图每一步降噪能实时预览吗」；拍板：**默认关 / 两级 / 镜像优先 / 16 帧 / 开工**。
**依据**：`docs/排查-实时预览可行性-20261013.md`（含机制取证）。

---

## 一、要达成的能力

1. 设置页新增「**实时预览**」开关（**默认关**）+ 档位选择（基础/高清）+ 高清档「下载模型」入口。
2. 开着时，出图过程每步预览帧进中继记录（**最近 16 帧**）。
3. 生成卡显示预览（小图 + 可回放）。
4. **免重启**：预览模式走提交时的 `extra_data.preview_method`。

---

## 二、三处落点（已探明，勿重探）

### A. 中继 `app/runtime/comfy-relay.mjs`
- **吞帧现场**（L1957 一带）：
  ```js
  ws.addEventListener("message", (ev) => {
    const data = typeof ev.data === "string" ? ev.data : "";   // ← 二进制帧 → "" → 丢
    if (data) { try { handleBackendEvent(data); } catch {} }
  });
  ```
  **修**：非字符串（`Blob`/`ArrayBuffer`/`Buffer`）分支 → 解析二进制帧。
  - ComfyUI 二进制帧格式：`[4字节事件类型(int32 BE)] + [4字节 payload 类型头?] + payload`。
    实测口径见 `protocol.py` / `server.py` 的 `BinaryEventTypes`（`PREVIEW_IMAGE_WITH_METADATA = 4`；`PREVIEW_IMAGE = 1`）。
    payload 对 `PREVIEW_IMAGE_WITH_METADATA` 为 **msgpack** `(image_tuple, metadata)`；旧版 `PREVIEW_IMAGE` 为裸 JPEG/PNG 字节。
  - **要求**：先**实地取一帧**确认格式（可临时打日志 dump 前 32 字节 + 长度），再写解析。
  - 解析后：抽 JPEG bytes → base64 → 存入 `promptRec(id).previewFrames`（**环形，最多 16 帧**），并记 `previewUpdatedAt`。
- **提交口**：`/_relay/submit-file`（L2546 一带）`promptReq` 加 `extra_data: { preview_method: <设置值> }`。
- **设置读取**：中继启动配置里加 `previewMethod`（由 app 通过 runtime 配置/`controlKey` 端点推送；**具体通道见下"C"**）。
- ⚠️ **中继是受管单文件**：改崩会导致整个服务起不来 → 必须有 `node --check` + 手动 `--standalone` 冒烟。

### B. app `app/index.js`（设置项 + 桥接）
- 新增设置文件 `app-data/comfyui-hana/preview-settings.json`：`{ enabled:false, tier:"basic"|"hd", frames:16 }`。
- 路由：`GET/POST /comfyui-hana/preview-settings`。
- **把设置传给中继**：复用中继已有的管理端点通道（`POST /_relay/custom-roots` 同款，带 `controlKey`）→ 新增 `POST /_relay/preview-config`；中继收到存内存 + 落盘。
- 模型下载：新增 `POST /comfyui-hana/preview-model/download` → 走 **hana-downloader**（镜像优先）；落 `models/vae_approx/`；返回进度。

### C. 卡片 `app/ui/task.html` + `assets/task.js`（+ 设计稿落地）
- 按新设计稿重做（时间轴 / 精简元信息 / 可点预览 / lightbox）。
- 预览区：显示 `previewFrames` 最新帧；可回放（16 帧）。

## 三、接口契约（先定，避免撞车）

```jsonc
// 设置（app 侧落盘）
{ "enabled": false, "tier": "basic", "frames": 16 }

// app → 中继
POST /_relay/preview-config  (header x-comfy-relay-key)
{ "enabled": true, "method": "latent2rgb" | "taesd" }   // 关 → method=null（不带 extra_data）

// 中继 → app（prompt 记录扩展）
promptRecord.previewFrames = ["data:image/jpeg;base64,...", ...]  // ≤16
promptRecord.previewUpdatedAt = 1712...
```

## 四、批次
| 批 | 内容 | 文件 |
|---|---|---|
| 1 | 中继：二进制帧解析 + 预览配置端点 + 提交带 extra_data | `runtime/comfy-relay.mjs` |
| 2 | app：设置项 + 桥接 + 模型下载入口 | `app/index.js` |
| 3 | 卡片：新设计 + 预览显示/回放 | `app/ui/task.html`、`assets/task.js`、`settings.*` |
| 4 | 部署 + **宿主 reload**（不重启 ComfyUI）+ 独立验证 | — |

## 五、边界
- **默认关**：不开则行为与现在完全一致（不带 extra_data，零开销）。
- **免重启**：不碰 ComfyUI 启动参数。
- **只下载模型**（几 MB），代码是 app 自带。
- 中继改动**必须冒烟**（单文件受管，崩了服务起不来）。
