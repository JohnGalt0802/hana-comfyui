## 1. 现象与根因

hui 工作区里 ComfyUI 的**左侧栏**不跟随宿主主题，停在 ComfyUI 内置色板原色（暗色 `#000` 系），与宿主主题脱节。

hui 把宿主主题写成 ComfyUI 自定义色板（id=`hana`）推给服务端，键表在 `app/ui/workspace.js` 的 `HANA_CSS_MAP`。

实测当前服务端状态（`GET http://127.0.0.1:8188/api/settings`）：

- `Comfy.ColorPalette = "hana"`（推送机制正常）
- hana 色板 `colors.comfy_base` 里**有** `interface-panel-hover-surface` / `interface-panel-selected-surface`（=`rgba(230,177,196,0.14)`）
- **没有** `interface-panel-surface`、**没有** `interface-stroke`

前端（`comfyui_frontend_package` 1.55.14）里 `interface-panel-surface` 是该 `interface-panel-*` 家族的**基底**变量：

```
"interface-panel-hover-surface":    color-mix(in srgb, var(--interface-panel-surface) 92.5%, var(--contrast-mix-color))
"interface-panel-selected-surface": color-mix(in srgb, var(--interface-panel-surface) 78%,   var(--contrast-mix-color))
"interface-button-hover-surface":   color-mix(in srgb, var(--interface-panel-surface) 82%,   var(--contrast-mix-color))
"interface-stroke":                 color-mix(in srgb, var(--interface-panel-surface) 75.5%, var(--contrast-mix-color))
```

hui 未覆盖基底 `interface-panel-surface` → 左侧栏面板底色不落在宿主色上，视觉上与宿主主题脱离。`interface-stroke` 同属该族的面板/栏位描边色，一并缺失。

## 2. 改动（最小）

`app/ui/workspace.js` 的 `HANA_CSS_MAP` 在现有 `interface-panel-*` 那组前补两条（沿用现有注释风格，带日期与理由）：

```js
  ["--interface-panel-surface", "--sidebar-bg"],
  ["--interface-stroke", "--border"],
  ["--interface-panel-hover-surface", "--accent-light"],
  ["--interface-panel-selected-surface", "--accent-light"],
  ...
```

### 补了哪几条 / 对应前端哪个键 / 为什么是它

| 补的条目 | 对应前端键 | 为什么是它 |
|---|---|---|
| `["--interface-panel-surface", "--sidebar-bg"]` | `comfy_base.interface-panel-surface` | 该键是 `interface-panel-*`（hover/selected/button-hover/stroke）全族的**派生基底**；缺失即左侧栏面板底色不携带宿主色。宿主取值用 `--sidebar-bg`，与既有 `--comfy-menu-bg ← --sidebar-bg` 口径一致 |
| `["--interface-stroke", "--border"]` | `comfy_base.interface-stroke` | 面板/栏位描边色，同属该族基色；缺失对面板边框同样退回内置原色。宿主取值用 `--border`，与既有 `--border-color ← --border` 口径一致 |

未新增第三类改动。

## 3. 全量对照结果

### 3.1 `comfy_base`（前端键 ≠ hui 映射）

前端 `comfy_base` 键全集（取用两个来源的并集，共 27 键）：

- 运行时色板 schema：`settingStore-*.js` 的 `Qf=Fr({...})`（含 `.optional()` 标记）
- 内置色板 JSON：同文件 `comfy_base:{...}`（dark/light/github/arc/nord/solarized 六块）并集

| 前端键 | hui 是否已映射 | 处置 |
|---|---|---|
| `bg-color` `fg-color` `comfy-menu-bg` `comfy-menu-secondary-bg` `comfy-menu-hover-bg` `comfy-input-bg` `input-text` `descrip-text` `drag-text` `error-text` `border-color` `tr-even-bg-color` `tr-odd-bg-color` `content-bg` `content-fg` `content-hover-bg` `content-hover-fg` `bar-shadow` `contrast-mix-color` `interface-panel-box-shadow` `interface-panel-drop-shadow` `interface-panel-hover-surface` `interface-panel-selected-surface` | 已映射 | 不动 |
| `interface-panel-surface` | **缺（本次补）** | 补 `--sidebar-bg`（该族基底，导致左侧栏退回原色） |
| `interface-stroke` | **缺（本次补）** | 补 `--border`（该族面板/栏位描边） |
| `interface-button-hover-surface` | 缺 | **不补**：按钮 hover 态，基色为 `var(--interface-panel-surface)`；补上基底后由 `color-mix(… var(--interface-panel-surface) 82%, var(--contrast-mix-color))` 自宿主色派生，非「面板/栏位退回原色」项 |
| `bg-img` | 缺 | **不补**：背景图 URL，非色值；不属面板/栏位底色问题 |

> 注：`HANA_CSS_MAP` 里另有 `component-node-*` / `node-component-*` 七条为 Vue 节点渲染变量，不在 `comfy_base` 键表内（hui 自扩展），列作「EXTRA」，无害、不动。
