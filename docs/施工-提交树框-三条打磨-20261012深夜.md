### 2b. 去掉泳道折叠（全量显示）
**现状**：`commitGraphLanes()` 内 `LANES_MAX_ROWS = 4`（L4580），超出 4 条的泳道被折叠为 `row=-1`，底部显示「+N 休眠分支」。
**目标**：**不再折叠**——所有泳道全部显示，交给用户自己拖。
**规格**：
- `commitGraphLanes`：取消 `LANES_MAX_ROWS` 截断，`display = 全部泳道`，`rows = laneCount`，`sleepingCount = 0`（`lanes[].sleeping` 恒 false）。
- 同步 `app/lib/commit-graph-lanes.mjs`（纯函数 + 单测）——**保持两者逐逻辑一致**（桥内内联版与 lib 版必须同改，含 `.test.mjs` 断言）。
- `.htr-sleep` 折叠条：不再显示（可保留元素但恒不展开，或移除逻辑）。
- 连线里「一端在折叠泳道 → 淡出短线」的分支：去折叠后该分支不再触发（保留代码无害，但确认不误画）。

### 2c. 拖拽平移（像画布一样）
**现状**：`.tcanvas` 仅 `overflow-x:auto` + 滚轮横滚；`cursor:grab` 但无拖拽。
**目标**：**在尺寸内按住拖动平移内容**（横 + 纵），不局限滚轮。
**规格**：
- `.tcanvas` 支持双向滚动（`overflow: auto`；隐藏滚动条）。
- 新增**拖拽平移**：`mousedown` 记录起点与 `scrollLeft/scrollTop` → `mousemove` 反向平移 → `mouseup` 结束；`cursor: grab/grabbing`。
- 高度：容器高度**封顶**（现 `H clamp ≤ 176`），泳道多时内容更高 → 靠纵向拖/滚查看。**高度上限数值由 worker 定**（保证面板不占满屏；建议 ≤ 200）。
- 拖拽不得干扰节点点击（`click` 需与拖拽区分：位移极小仍视为 click）。
- 两端渐隐（`.htr-fade`）保留，随滚动更新。

**验收**：>4 泳道时全部可见（无「+N 休眠分支」）；按住空白处可横/纵拖动画布；节点单/双击仍正常。
