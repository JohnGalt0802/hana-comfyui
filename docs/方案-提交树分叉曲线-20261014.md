# 方案 · 提交树跨泳道分叉线改优雅 S 曲线（2026-10-14）

> **需求**（John 2026-10-14）：提交树的分叉线用**优雅点的曲线**。

---

## 1. 现状与问题

`historyTreeDrawEdges()`（约 L5766）跨泳道分支当前是「短水平 + 竖直 + 水平」的**阶梯 + Q 圆角（R=6）**（上一轮实现）。R=6 太小，观感仍接近直角，不够优雅。

**约束**（历次迭代沉淀，必须同时满足）：
- **不能退回长水平横穿**（控制点若取 `(x1+x2)/2`，中段是长水平 → 曾观感"遮挡"）；
- **分叉要早**（在父节点附近就开始转向，不拖很远）；
- **曲线要平滑优雅**（连续弯曲，非折线）。

---

## 2. 改法：对称三次贝塞尔 S 曲线（控制点小偏移 + 封顶）

跨泳道 `else` 分支，整段替换为**一条三次贝塞尔**：

```js
const branchIdx = branchCount.get(p) || 0;
branchCount.set(p, branchIdx + 1);
const xr = pRect.r;                 // 父右边缘
const xl = cRect.l;                 // 子左边缘
const dx = xl - xr;
// 控制点水平偏移：取 dx 的一半（标准平滑 S），封顶 44 防远距中段变长水平横穿；
// 同父多子按序 +6 递增，避免多条曲线完全重合。
const K = Math.min(dx * 0.5, 44) + branchIdx * 6;
const kk = Math.max(0, Math.min(K, dx * 0.85)); // 防控制点越过对端
d +=
  "M" + xr.toFixed(1) + " " + pcy.toFixed(1) +
  "C" + (xr + kk).toFixed(1) + " " + pcy.toFixed(1) +      // 控制点1：向右引出（水平出发）
  " " + (xl - kk).toFixed(1) + " " + ccy.toFixed(1) +      // 控制点2：从左侧接入（水平到达）
  " " + xl.toFixed(1) + " " + ccy.toFixed(1);
```

**为什么这样满足三约束**：
- **平滑**：三次贝塞尔整段连续弯曲，无折角；
- **不横穿**：控制点封顶 44 → 中段是"斜向平滑过渡"而非长水平；且节点已不透明底，线经过节点被遮；
- **分叉早**：控制点1 紧邻父节点（偏移 ≤44）→ 出父后很快开始下沉；
- **同父多子**：`branchIdx*6` 递增偏移 → 各曲线略有差异，不重叠。

**保留**：同泳道水平直线分支、折叠淡出线、`trimToEdge`、`branchCount` 计数（现用于多子错开）。
**移除**：原阶梯 + Q 圆角那段（含 GAP/R 常量、过近回退分支——贝塞尔对近距离天然平滑，无需特判）。

## 7. 迭代 2（2026-10-14，用户真机反馈）：改为非对称控制点 → 更早分叉

**反馈**：曲线平滑了，但要**更早分叉**。

**数学本质**：对称三次贝塞尔（`P1=(xr+K,pcy)`、`P2=(xl-K,ccy)`）的 y 演进只依赖 t（`y(t)=pcy·(1-t)²(1+2t)+ccy·t²(3-2t)`），**t=0.5 时 y 恒为中点高度** → 无论 K 怎么调，曲线都在**中点**附近才明显下沉 → 看着"走了一段才分叉"。

**修法：控制点改非对称**（起点偏移小、终点偏移大）：
- 中点 x 偏移 = `0.375·(k1 − k2)`；`k1 < k2` → 中点左移 → **下沉提前**。
- 起点偏移小 → 出父后更早转向；终点偏移大 → 接入子时仍平缓（保持优雅）。

参数：
```js
const k1 = Math.min(dx * 0.20, 14) + branchIdx * 5;  // 起点控制点：小 → 更早下沉
const k2 = Math.min(dx * 0.70, 56);                  // 终点控制点：大 → 平缓接入
const kk1 = Math.max(0, Math.min(k1, dx * 0.5));
const kk2 = Math.max(0, Math.min(k2, dx * 0.92));
d += "M" + xr + " " + pcy +
     "C" + (xr + kk1) + " " + pcy + " " + (xl - kk2) + " " + ccy + " " + xl + " " + ccy;
```

**验收**：跨泳道曲线**明显更早**开始下沉（不再走到中点才弯），且仍平滑无折角。
