# 方案 · 提交树连线优化（不遮挡节点 + 更快分叉）（2026-10-14）

> **需求**（John 2026-10-14，附截图）：优化提交树的连线——① 连线不应遮挡提交节点；② 连线更快分叉，避免遮挡。

---

## 1. 现状与根因（已读代码坐实）

**连线绘制**：`historyTreeDrawEdges(nodeEls, graph)`（约 L5615）。跨泳道父子用**贝塞尔**：
```js
const mx = (x1 + x2) / 2;                         // 控制点在水平中点
d += "M x1 y1 C mx y1, mx y2, x2 y2";             // 长水平出发 + 长水平到达 的 S 形
```
父子 X 相距远时，曲线中段是**很长的近水平段**，横穿中间泳道行 → 视觉"压过一排节点"。

**"遮挡"的观感来源**：节点底色 `background: rgba(255,255,255,.025)`（约 L4949）**几乎全透明**。连线层 `z-index:0` 虽在节点 `z-index:1` 之下，但线从节点矩形区域经过时**透出来可见** → 看起来像"线压在节点上"。

**层序（已正确）**：`.htr-edges { pointer-events:none; z-index:0 }` < `.node { z-index:1 }`。问题不在层序，在"节点不遮底 + 线横穿"。

---

## 2. 改动（桥 js，两组）

### 2.1 节点底色改为不透明（治"线透出节点"）

`.node` 的 `background: rgba(255,255,255,.025)` → 改为与面板底协调的**不透明深色**：
```css
background: #1e242c; /* 面板底 rgba(38,44,54,.94)→rgba(27,32,40,.95) 的中间调，不透明 */
```
效果：连线经过节点矩形时被节点遮住，不再"透出"。悬停 `filter: brightness(1.25)`、选中 outline、内条堆、光晕均不受影响。
- 密档 `[data-tight]`、合并 `.htr-tick-bulge`、`[data-legacy]` 等既有规则不动。

### 2.2 跨泳道连线改「阶梯折线」+ 更快分叉

把跨泳道的贝塞尔改为**阶梯走线**：`父节点右边缘 → 父右侧 GAP 处分叉 → 竖直迁移到子泳道 → 水平到子节点左边缘`。拐角由既有 `stroke-linejoin: round` 自然圆润。

几何（在 `historyTreeDrawEdges` 的 else 分支，替换贝塞尔）：
```js
// 端点用节点矩形边缘（不用中心角向裁剪，阶梯需要水平出入）
const GAP = 10; // 分叉点距父节点右边缘的距离（越小分叉越快）
const xr = pRect.r;  // 父右边缘
const xl = cRect.l;  // 子左边缘
if (xl - xr <= 2 * GAP) {
  // 太近：退化为直线（父右边缘 → 子左边缘）
  d += "M" + xr.toFixed(1) + " " + pcy.toFixed(1) + "L" + xl.toFixed(1) + " " + ccy.toFixed(1);
} else {
  const xb = xr + GAP;              // 分叉点：靠近父节点（更快分叉）
  d +=
    "M" + xr.toFixed(1) + " " + pcy.toFixed(1) +
    "L" + xb.toFixed(1) + " " + pcy.toFixed(1) +   // 短水平引出
    "L" + xb.toFixed(1) + " " + ccy.toFixed(1) +   // 竖直迁移（集中在一根竖线）
    "L" + xl.toFixed(1) + " " + ccy.toFixed(1);    // 水平到子（在子泳道行内）
}
```
**同一父多个子（分叉错开·加固）**：若一个父节点有多个跨泳道子，各子竖直段都用 `xr+GAP` 会**重叠成一根竖线**。改为按子出现序递增 GAP：`xb = xr + GAP + i * 5`（`i` = 该父下的第几个跨泳道子，从 0 起；实现时按父分桶计数）。实现可按最小改动：一次遍历按 `parent` 分组，组内序号递增偏移。

效果：
- **更快分叉**：Y 迁移集中在父节点右侧 `GAP=10px` 处的**一根竖线**，不再有长 S 曲线的散开转向；
- **减少横穿**：长水平段落在**子泳道行**（子节点同排），不再斜穿中间多行；
- 拐角圆润（`stroke-linejoin:round`）；如仍嫌角硬，可后续加 `Q` 圆角（本方案先直角+round）。

**同泳道**（`pRow === cRow`）：保持水平直线（不变）。

**折叠分支淡出线**（`faded`）：不变。

**边界**：`pcy/ccy` 用节点中心 Y；`pRect/cRect` 已算（沿用现有变量）。若子节点在父左侧（异常，正常不会），`xl - xr` 为负 → 走退化直线分支，不至于画错。

## 5. 验收标准

1. 连线**不再透出**节点（节点矩形内看不到线穿过）。
2. 跨泳道连线在父节点附近**快速分叉**（短水平 + 一根竖线 + 水平到子），不再有横穿多行的长斜线。
3. 同泳道水平直线、折叠淡出线、回跳/气泡/缩略图等**不回归**。
4. 与提交历史框（弹层）观感一致。
