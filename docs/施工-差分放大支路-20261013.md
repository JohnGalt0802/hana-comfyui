## 一、术语落定

「差分扩图」非标准术语。社区对应：`[ComfyUI]局部放大重绘，**差分扩散融图**`——用 `DifferentialDiffusion`（差分扩散）让去噪强度按 mask 变化，实现画面融合。
本机已装：`DifferentialDiffusion` / `DifferentialDiffusionAdvanced`（`comfy_extras/nodes_differential_diffusion.py`）。

**机制（实测源码）**：`DifferentialDiffusion.execute` → `model.set_model_denoise_mask_function(...)`，按 `denoise_mask` 调制 sigma。**须配 `SetLatentNoiseMask` 提供 mask**，否则 mask 全 1 = 普通去噪。

**John 选高清放大 → 差分的落点**：放大后用 `SetLatentNoiseMask`（mask 值≈0.45）压低有效去噪强度，等于「低 denoise 二次采样」，同时差分扩散让去噪可控。mask 值即「重绘强度」旋钮。

---

## 二、架构（关键：避开环形依赖）

**约束**：放大源图若取自「当前采样输出 #24」，会与放大链构成环（#23→#24→编码→放大→#23）。**必须拆断**。

**解法**：`ComfySwitchNode` 是 **lazy**（`"lazy": true`，实测 object_info）——未选中的分支上游**不执行**。于是：

```
                 ┌─ OFF ─→ #24(生图 decode) ─────────────┐
#101 最终输出(switch)                                   ├─→ #25 SaveImage
                 └─ ON  ─→ #112(放大 decode) ─┐         │
                                             │         │
#102 放大源图(switch) → #105 VAEEncode → #106 LatentUpscaleBy(×2)
   ↑ on_false=#24(链式)                      → #107 SetLatentNoiseMask ← #108 SolidMask(0.45)
   ↑ on_true =#104 LoadImageOutput(选图)     → #111 SamplerCustomAdvanced
                                               ↑ noise=#20 guider=#110 sampler=#21 sigmas=#22
                                             #110 BasicGuider ← #18.positive, #109 DifferentialDiffusion
                                             #109 DifferentialDiffusion ← #26(EasyCache)
                                             → #112 VAEDecode → #101.on_true
```

**效果**：
- **OFF**：`#101` 取 `#24` → 只算生图链；放大链因 lazy **不执行**。生图行为**零改动**（唯一改动＝`#25.images` 的来源换成 switch 输出）。
- **ON + 源=链式**：跑生图 → 其结果进放大链 → 出放大图。
- **ON + 源=选图**：直接对所选图放大。

- #111 复用 #20(noise)/#21(sampler)/#22(scheduler)；放大去噪靠 #108 mask 控制
