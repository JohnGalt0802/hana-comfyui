## 第 1 条 · 树节点也要「多生成宽、单生成窄」

**现状**：树 `.node` 宽度 = `--nw = clamp(6, colW-2, colW*0.8)`（**只随列宽**）；合并提交只加**边框粗细**（`.htr-tick-bulge` border 2.5px），**不加宽**。
**框图对照**：框 `.hhb-tick` 合并时 `.hhb-tick-bulge{ width: calc(var(--hhb-tw)+3px) }`（**加宽 3px**）。
**目标**：树也照框口径——**合并提交（runs>1）的节点比单次生成更宽**。
**规格**：`.node.htr-tick-bulge { width: calc(var(--nw) + 3px); }`（与框同 +3px）；或按 `runs` 数分级（若 worker 认为单档不够，可 `min(3, runs-1)*2px`，但默认先与框一致 +3px）。
**验收**：多次生成的树节点肉眼比单次明显更宽；同时保留边框加粗。

## 第 2 条 · 树预览浮层：再点节点才消失 + 图内左右翻页

**现状**：树预览 `.htr-shots` **鼠标移出 180ms 自动关**（`mouseleave → historyTreeShotsHideSoon`）；点图开 lightbox（无翻页）。
**目标**：
- **2a 改为「再点同一节点才关」**：去掉鼠标移出自动关；再次单击**同一节点**关闭其浮层（点别的节点 → 切到新节点预览）。参照框 `.hhb-shots` 现有行为核对——若框也是"移出即关"，本条**只改树**（用户只点了树）。
- **2b lightbox 加左右翻页**：点图进全屏后，可左右切换**该提交内的多图**（及/或跨提交？——按下文实现：**先做「同一提交内多图」左右翻**，这是最小明确语义；若跨提交需另议）。加左右箭头（`←/→`）+ 键盘左右键；单图时箭头隐藏。
**规格落点**：`historyTreeShotsToggle`（去 hover 关、加 toggle 判定）、`historyOpenLightbox`（加翻页参数：`{list, index}`）。
**验收**：点节点出浮层 → 再点同节点消失；点别的节点切换；点图进全屏 → 左右箭头/键盘可翻同提交的多图。

## 第 3 条 · 框节点：宽窄不一 + 内条圆角 + 同款发光边缘

**现状**：`.hhb-tick` 已有合并加宽（`bulge` +3px）、外框加粗；**内条 `.hnode-bar` 是 `border-radius:1px`**（近方）；外框**无光晕**（仅 hover 有）。
**目标**（断句确认版）：
- **3a 宽窄不一的成因确认 + 保留**：节点因 `bulge` 而宽窄不一（合并更宽）——这是特性，保留；若用户嫌"不一"难看，指"即便都是单次生成也宽窄不一"→ 查是否 `tw` 随 `colW` 抖动。**先诊断给结论**。
- **3b 内条加圆角**：`.hnode-bar` 圆角加大（如 `border-radius: 2px`~`50%` 胶囊；按观感，密档细条宜 1px）。
- **3c 外框加"跟树一样的发光边缘"**：树节点**常态**有 `box-shadow` 光晕吗？核对：树 `.node` 常态只有 `border`+淡背景，**合并时**才 `box-shadow:0 0 9px ...`。框 `.hhb-tick` 常态无光晕。→ 用户要"发光边缘"= 给框节点**常态**加一层柔和外发光（`box-shadow: 0 0 6px color-mix(--hhb-c 40%)`），与树统一。**若树常态也应有光晕，一并加**（两视图统一口径）。
**验收**：框内条有圆角；框节点常态有柔和同色光晕；与树观感统一。

## 第 4 条 · 框预览：点 bondle 框开、再点同框关（现在点不开→关）

**现状**：`historyOnCanvasMouseDown` 命中 group → `historyBarOpen(group)`（**无条件重开**，不判断是否已开同一框）；点空白 → 关。
**目标**：**点同一个框 = 开/关切换**（已开该框则关；已开别的框或未开 → 开）。
**规格**：命中 group 时，若 `historyBarEl` 已存在且 `historyBarGroup === group`（同框）→ `historyBarClose()`；否则 `historyBarOpen(group)`。注意 `historyBarGroup` 现存的引用比较是否可靠（同一 group 对象；切图后可能失效）。
**验收**：单击框开弹层；再单击同一个框关闭；单击别的框切换。

## 第 5 条 · 框节点再加宽

**现状**：`tw = Math.min(15, Math.max(4, colW*0.6))`，再 `tw = min(tw, colW*0.86)`。
**目标**：节点比现在**更宽**（用户嫌细）。
**规格**：上限 `15 → 20`（观感 18~22），系数 `0.6 → 0.7`；保持 `colW`（=间距）不变、`gap ≥ 2px`。
**验收**：框节点明显更宽；间距不变、不粘连。
