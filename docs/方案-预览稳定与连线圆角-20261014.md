## 1. 问题一 + 三：预览浮层「锚点不定 + 顶边钉死 + 异步图片」（同源）

**两处代码**：
- 树：`historyTreeShotsToggle()`（约 L5514）尾部定位段。
- 弹层：`historyBarShotsToggle()`（约 L3822）尾部定位段。

**根因（四条）**：
1. 定位时读 `offsetHeight` 算 `top`，浮层内 `<img loading="eager">` **异步加载** → 那一刻高度只是占位（偏小）；`top` 一次性写死 → 图片加载后元素**向下生长** → 浮层底边下移，**盖住面板**。
2. **树额外不稳定源**：`const bub = historyTreeEl.querySelector(".htr-bubble")` —— 气泡在场时锚气泡上方、不在场时锚节点上方；同一节点两次点开可能落两个不同位置（悬停时序 + 气泡高度随内容变）→ "位置很不稳定"。
3. **弹层额外问题**：锚「被点刻度上方」，而刻度在弹层中部 → 浮层天然压住弹层标题行。

**修法（两视图共用一套定位逻辑，但锚点不同）**：

**(a) 锚点语义**
- **树**：打开时**快照锚点**（`anchorTop`）——气泡在场取气泡顶、否则取节点顶（局部坐标），存进闭包/`box.dataset`；重定位时**复用该快照**，不再重查气泡 → 位置稳定。`top = anchorTop - bh - 6`（保留"预览叠在气泡上方"）。
- **弹层**：锚**整个弹层上方**（不再锚刻度）—— `top = -bh - 8`（相对弹层顶边）。若弹层上方视口内放不下（`barRect.top - bh*k - 8 < 4`）→ 落到弹层**下方** `top = barHeight + 8`（仍不盖弹层）。
- **水平**：两视图均居中于被点节点/刻度，并钳在宿主宽度内（保留原水平算法）。

**(b) 图片 load/error 后重定位**：抽出定位函数 `historyTreeShotsPosition(box, tick)` / `historyBarShotsPosition(box, tick)`，append 后调一次；并给每张缩略图加：
```js
img.addEventListener("load", () => { try { position(box, tick); } catch {} });
img.addEventListener("error", () => { try { position(box, tick); } catch {} });
```

**(c) 位置语义**：底边锚定（`top = anchorTop - 高度 - gap`）。图片加载变高 → top 变小 → 浮层**向上生长**，底边不动。

> 效果：树浮层稳定叠在气泡/节点上方；弹层浮层稳定在**弹层上方**、不盖弹层；两边图片加载后都不跳。

## 2. 问题二：连线改「Q 圆角」（保留快分叉）

**位置**：`historyTreeDrawEdges()`（约 L5615）跨泳道 `else` 分支（当前直角阶梯）。

**做法**：保留「短水平引出 → 竖直迁移 → 水平到子」的**快分叉骨架**（分叉点 `xb = xr + GAP + branchIdx*5` 紧贴父节点右侧），把**两个直角拐点改成 Q 圆角**：

```js
const GAP = 10;
const R = 6;                       // 圆角半径
const xr = pRect.r;                // 父右边缘
const xl = cRect.l;                // 子左边缘
if (xl - xr <= 2 * GAP + R * 2) {
  // 过近：一条短贝塞尔（短距离不会遮挡）
  const mx = (xr + xl) / 2;
  d += "M" + xr.toFixed(1) + " " + pcy.toFixed(1) +
       "C" + mx.toFixed(1) + " " + pcy.toFixed(1) +
       " " + mx.toFixed(1) + " " + ccy.toFixed(1) +
       " " + xl.toFixed(1) + " " + ccy.toFixed(1);
} else {
  const branchIdx = branchCount.get(p) || 0;
  branchCount.set(p, branchIdx + 1);
  const xb = Math.min(xr + GAP + branchIdx * 5, xl - R - 2);
  const sy = ccy >= pcy ? 1 : -1;  // 向下 / 向上迁移
  const r = Math.max(0, Math.min(R, Math.abs(ccy - pcy) / 2, Math.abs(xb - xr) / 2, Math.abs(xl - xb) / 2));
  d +=
    "M" + xr.toFixed(1) + " " + pcy.toFixed(1) +
    "L" + (xb - r).toFixed(1) + " " + pcy.toFixed(1) +
    "Q" + xb.toFixed(1) + " " + pcy.toFixed(1) + " " + xb.toFixed(1) + " " + (pcy + sy * r).toFixed(1) +
    "L" + xb.toFixed(1) + " " + (ccy - sy * r).toFixed(1) +
    "Q" + xb.toFixed(1) + " " + ccy.toFixed(1) + " " + (xb + r).toFixed(1) + " " + ccy.toFixed(1) +
    "L" + xl.toFixed(1) + " " + ccy.toFixed(1);
}
```
- 分叉仍**紧贴父节点**（"更快分叉"）；拐角 `Q` 圆滑（"曲线圆角"）；`r` 自适应避免圆角吃掉整段。
- **保留**：同泳道水平直线分支、折叠淡出线、`trimToEdge`、`branchCount`。

## 5. 验收标准

1. **预览稳定**：反复点开同一节点（含下方泳道）→ 浮层位置**固定不变**；图片加载完不再跳。
2. **不遮面板**：树浮层稳定叠在**气泡/节点上方**；弹层浮层出现在**弹层上方**，**不覆盖**弹层内容。
3. **连线圆角**：跨泳道连线**分叉紧贴父节点**、拐角是**圆滑曲线**（非直角）。
4. 连线不遮挡节点（上一轮节点不透明底保留）；同泳道直线、折叠淡出、回跳/存档等**不回归**。
