# T11 · 真机验收清单（给 John 照着点）

前提：ComfyUI 服务在线（8188），Hana 宿主已重载到 v0.24.0（文档改动需同步宿主后生效；同步与重载时机由你定）。

## 1. 校验正常图

- **怎么点**：对一张能正常出图的已存工作流跑 `comfyui(action="validate", template="<名字>")`（或传文件路径）。
- **看到什么算过**：返回「校验通过：N 个节点…」，`details.comfyui.valid = true`，errors 为空。

## 2. 校验坏 checkpoint

- **怎么点**：把那张图的 checkpoint 改成一个不存在的名字（或直接给一个含错误模型名的 JSON），再跑 `validate`。
- **看到什么算过**：返回「校验未通过」，错误里能看到**节点 id、字段名**，且带**可选项建议**（suggestions，真实存在的 checkpoint 名，最多 8 个）；code 为 `enum_mismatch`。

## 3. 模板检索

- **怎么点**：`comfyui(action="templates", op="list", q="flux")`；再试中文关键词（如 `q="人像"`）和 `recommend="highly_recommended"`。
- **看到什么算过**：返回模板清单（名称/中文标题/模型族），●推荐标记正常，limit/offset 分页可用。
- **顺带确认数据现状**：`mediaType="video"` 过滤命中 0 条（上游索引把视频模板标成了 image，属已知数据事实，不算故障）。

## 4. 模板拉取（落盘位置）

- **怎么点**：挑一个模板 `comfyui(action="templates", op="fetch", name="<name>")`。
- **看到什么算过**：返回落盘路径形如 `<ComfyUI>/user/default/hui-templates/<分类>/<name>.json`，文件确实在那里；**ComfyUI 前端的工作流列表里看不到它**（刻意避开 workflows/，不污染列表）。

## 5. 模板上画布

- **怎么点**：拿 fetch 返回的**绝对路径**，`comfyui(action="canvas", op="openWorkflow", ...)` 装载。
- **看到什么算过**：画布完整装载该模板（注意装载路径纪律：副驾驶未开时会走复制副本）。

## 6. 缺包诊断给候选

- **怎么点**：拿一张用了第三方节点包的工作流（本机没装的包），`comfyui(action="deps", workflow="<路径>")`。
- **看到什么算过**：三段式摘要里该类落在「没装」段，按仓库列出候选（标题 + repo），不自动安装、不重启；多候选类名有"对应多个包"标注。

## 7. 带 subgraph 的模板校验不满屏 unknown

- **怎么点**：拉一个官方含 subgraph 的模板（模板库里不少），先 `fetch` 再对落盘文件跑 `validate`。
- **看到什么算过**：子图被展开后逐节点检查，**没有满屏 `unknown_type`**；子图相关的问题（如有）以 `subgraph_unexpanded` / 警告呈现，且每条都带可读的中文定位。
