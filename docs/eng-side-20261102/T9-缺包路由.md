## 请求与响应

```
POST /_relay/node-deps
Headers: x-comfy-relay-key

Body 二选一：
{ "classes": ["SomeNode", "OtherNode"] }
{ "workflow": {path|template|object} }     // 中继自己先算出图里有哪些类
```

响应：

```jsonc
{
  "ok": true,
  "checked": 27,
  "unknownCount": 3,
  "resolutions": [
    { "className": "SomeNode", "candidates": [{ "repo": "owner/repo", "title": "...", "installed": false }] }
  ],
  "summary": {
    "notInstalled": [{ "repo": "...", "title": "...", "classes": ["..."] }],
    "installedNotLoaded": [{ "repo": "...", "dir": "custom_nodes/xxx", "classes": ["..."] }],
    "unresolved": [{ "className": "..." }]
  },
  "source": { "map": "cache", "mapAge": 86400, "customNodes": 24, "gitRepos": 13 }
}
```

`workflow` 形态时，`classes` 由中继自己从工作流里提取（要递归进 `definitions.subgraphs[].nodes[]`），再与本机 object_info 的类名集合求差。

## 要做的事

1. 加 handler + 路由。
2. 读映射表：先 glob cache 目录取最新，失败再回落 site-packages 那份。两份都读不到 → 返回 `ok:false, error:"node_map_unavailable"`，不要静默返回空。
3. 扫 `custom_nodes`：只读 `.git\config`，不做任何写操作。把 `git@github.com:owner/repo.git`、`https://github.com/owner/repo`、`https://github.com/owner/repo.git` 三种写法归一。
4. object_info 的类名集合走 T1 的缓存函数，不要自己拉。
5. 结果不缓存（映射表变了就得重算），但映射表本身可以缓存，按 mtime 失效。
