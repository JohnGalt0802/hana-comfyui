## 外网数据源

| 用途 | 地址 |
|---|---|
| 索引（英文,mcp） | `https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/index.mcp.json` |
| 索引（中文） | `https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/index.zh.json` |
| 单模板 | `https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/<name>.json` |
| 镜像兜底 | 把前缀换成 `https://cdn.jsdelivr.net/gh/Comfy-Org/workflow_templates@main/templates/...` |

实测：raw 有弱 ETag（git blob SHA）+ `Cache-Control: max-age=300`，`If-None-Match` 返回 304；jsDelivr 与 raw 逐字节一致、CORS `*`、`max-age=604800`，但分支镜像最长有 12 小时 CDN 延迟。

## 要做的事

### 路由一：检索

```
GET /_relay/templates?q=&task=&model=&mediaType=&tag=&recommend=&limit=20&offset=0
```

- 索引缓存落盘（放中继自己的数据目录），带 `If-None-Match` 条件请求，304 就直接用本地的。
- raw 失败（超时/DNS/非 2xx）**自动回落 jsDelivr**，并在返回里标 `source:"jsdelivr"`。两条都失败才报错，错误信息要写清两个地址都试过。
- 索引超过 24 小时强制刷新一次；用 `?refresh=1` 可手动强刷。
- 返回里带 `indexAge`（秒）与 `source`，让 App 侧知道数据新不新。

### 路由二：拉取

```
POST /_relay/template-fetch
Headers: x-comfy-relay-key
Body: { "name": "image_qwen_image_2_1_t2i", "target": "hub" }
→ { ok, name, path, bytes, models: { required, missing, present }, runnable }
```

- `name` 必须先在本索引里存在，否则 400（防止被当成任意 URL 代理）。
- 落盘位置：**待 John 拍板**。默认按 `"target":"hub"` 写到 `user\default\workflows\_hub\<name>.json`；`"target":"tmp"` 写到临时目录不上列表。两种都实现，用参数选。
- 目录不存在要创建。同名文件已存在时 default 覆盖前先写 `.bak`（跟现有 save 的习惯一致）。
- 写完回填三件事：文件字节数、模板要求的模型清单、缺哪些（扫本地 `models/` 子目录比对）、版本是否满足。
- **禁止**写进 `workflows\` 根目录（会被工作流列表当正式条目）。

## 禁止

- 不得把这个路由做成通用 HTTP 代理（只允许固定的三个地址模板）。
- 不得把整份索引塞进内存不释放，也不得每次请求都重拉。
- 不得在拉取时自动下载模型权重。只报缺什么。
