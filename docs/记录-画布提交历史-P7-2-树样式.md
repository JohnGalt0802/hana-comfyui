## 二、实现口径

### 2.1 全局框列表（从 entries 收集）
在 `historyTreeRenderTree` 内、渲染前扫一遍 `entries`：

```
const globalBlocks = [];            // 框名并集，按首次出现序
const blockSeen = new Set();
for (const ent of entries) {
  const bl = Array.isArray(ent.blocks) ? ent.blocks : [];  // 兼容旧数据（只有 {name,nodeCount}）
  for (const b of bl) {
    const nm = b.name == null ? "" : String(b.name);       // name 缺省补 ""
    if (!blockSeen.has(nm)) { blockSeen.add(nm); globalBlocks.push(nm); }
  }
}
const singleBar = globalBlocks.length === 0;               // 空 → 单根色条兜底
```

- 口径与后端 `_norm_blocks`（`history_store.py` L342）一致：`name` 缺省 `""`；旧数据 `{name,nodeCount}` 也取 `name`。
- **列表为空 → `singleBar=true`**：每节点只渲染 1 根色条（命中亮色），不报错、不留白。

### 2.2 节点形态（竖排色条堆 + stem）
`cell` 内不再放 `strip + tick`；`tick` 改为一个容器 `button`（保留类名 `.htr-tick`，事件/连线语义不变），内部：

```
node (.htr-tick, button)
 ├─ .htr-bars            ← 竖排色条堆（flex column, gap 1px）
 │    └─ .htr-bar × N    ← N = 全局框数（空则 ×1）；14×3px，间距 1px
 └─ .htr-stem            ← 竖线，2×10px；data-kind 分 run/save
```

- **命中判定**：`legacy`（`blockNames` 非数组）→ 全灰；`singleBar` → 单根亮色；否则 `hit = hitSet.has(框名)`（`hitSet = new Set(ent.blockNames.map(String))`）。
- **亮色** = 该提交 `source` 色，复用 `historyTickColor(ent.source)`（user 冷蓝 `#5aa0d8` / agent 暖紫 `#b189e0`），以 CSS 变量 `--htr-c` 写到节点与每根条上。
- **灰** = `rgba(255,255,255,.18)`（`.htr-bar-off`）。
- **stem 表 kind**：`run` → 实线；`save` → `repeating-linear-gradient` 虚线（同参考卡 `.stem` 形态）。颜色同 `--htr-c`。
- **旧数据**：`cell.dataset.legacy="1"`（保留原标记），`.htr-cell[data-legacy] .htr-bars/.htr-stem { opacity:.55 }`。
- HEAD 高亮（`.htr-tick-head::after` 金点）、点选（`.htr-tick-sel` outline）、悬停气泡 / 回跳事件**全部保留**——事件仍绑在 `.htr-tick` 容器上。

### 2.3 布局调整
- `.htr-row`：`min-height: 20px → 24px`；`align-items: stretch → flex-end`（节点贴行底，色条堆向上生长）。
- `.htr-cell`：`justify-content: center → flex-end`，`min-width: 10px → 16px`（色条宽 14px，留边）。
- `.htr-row` 由 `flex: 1 1 0` 改 `flex: 0 0 auto`（行高由内容定；`.htr-tree` 保持 `overflow:auto`，靠上下滚动兜住，不再压缩行）。
- `.htr-panel` 高度仍 200px（不变）；行数超出 → 树容器内滚动。

### 2.4 移除的死样式
- 删 `.htr-strip`（横条）与其在 `.htr-cell[data-legacy]` 选择器里的引用。
- `.htr-tick` 不再有 `width:9px;height:16px` 实心柱 / `[data-kind=save]` 空心环规则（形态迁到 `.htr-stem`）。
- `data-kind` / `data-src` 仍写在 `.htr-tick` 上（`data-src` 保留，`data-kind` 现主要由 `.htr-stem` 承载）。

4. **`bubble/Pick` 传参未变**：事件回调仍传节点元素（`tick` 形参名保留为 `node`），`historyTreeBubbleShow(tick, ent)` 内部按元素测量定位，语义不变。
