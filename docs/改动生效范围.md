# hui 改动生效范围

> 2026-10-08 由主脑补立（AGENTS.md 既有引用，此前空悬；口径由 M5/M6 记录、bridge-reload/deploy-bridge/sync-to-host 脚本注释与两轮收尾实测沉淀）。

## 生效方式速查

| 改动位置 | 生效方式 | 说明 |
|---|---|---|
| `app/bridge/__init__.py`（py，部署为 custom_nodes/hana_bridge） | 部署（`tools/deploy-bridge.ps1`）+ **重启 ComfyUI 服务** | py 由服务进程加载，热更不生效 |
| `app/bridge/js/**`（前端扩展） | 部署（含改名绕缓存，`tools/bridge-reload.ps1` 口径）+ **重载工作区页面** | 免重启服务（server.py 每请求扫描直出 `/extensions`）；改名＝ddHHmmss 时间戳 |
| `app/index.js`（工具/路由/任务桥） | 同步宿主副本（`tools/sync-to-host.ps1`）+ 宿主重载/重启 | M6：本地目录 App 可 extension_manager reload；边界：reload 后工具 RPC 可能需要重启恢复 |
| `app/ui/**`（工作区/面板/设置页） | 同步 + 宿主重载/重启 | ui 受宿主 iframe 缓存，重启最稳 |
| `app/lib/**`（纯函数/分析） | 同步 + 宿主重载/重启（随 index.js） | — |
| `skills/**`、`docs/**` | 随仓库同步；不影响运行态 | — |
| 配置 / 数据（app 数据目录 json） | 即时生效 | 读写即用 |

## 部署与同步要点

- **同步**：`tools/sync-to-host.ps1`（全量校验，排除 `.git`）；脚本为增量非 purge——宿主副本允许存在历史沉积文件（多出条目属正常）。
- **部署桥**：`tools/deploy-bridge.ps1` 复制 js/ 与 py 到 custom_nodes；js 目录清空重建（防双载）；**非 js\ 文件无 bak 过滤**，本地 `.bak` 会被一并带入（无功能影响）。
- **构建标识三处同源**：js 文件名（ddHHmmss）＝ js `BUILD_TAG` ＝ py `BRIDGE_BUILD_TAG`；改名前排查仓内硬编码桥文件名的脚本（自检脚本等）并同步。
- **推荐执行顺序**：同步 + 部署 → 宿主重载/重启 → ComfyUI 服务重启 → 工作区页面刷新。

## 重启纪律

涉及宿主重启 / 服务重启 / 工作区重载的动作一律"先说再动"，**禁止静默重启**；收益清单与时机由用户定。
