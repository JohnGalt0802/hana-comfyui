## 一、统一母题：外框 + 内条

**外框** = 元素本身的 border。**内条** = 框内竖排小色条，每根 = 本次提交触及的一个画布框。

```
外框（border）
  ├ border-style: solid=提交 / dashed=保存      ← 操作
  ├ border-color: 蓝#5aa0d8=user / 紫#b189e0=agent  ← 谁
  ├ border-radius: 4.5px ; padding: 3px 3.5px
  ├ min-width: 15px
  └ 内条堆（flex column, gap 1.5px）
       └ <i> 每根: height 3px; border-radius 1px; width 100%
                   background = 该画布框的框色（活图取色）
                   命中当前框 → 加亮 brightness(1.55) + 光晕
                   取不到色（框已不在画布）→ 中性灰 rgba(255,255,255,.16)
```

- 无框（老数据/无 group）→ 退化为**单根中性灰内条**（沿用旧 `singleBar` 语义）。
- 旧数据（`blockNames === null`）→ 保留 `data-legacy` 淡化。

## 二、内条取色（关键链路）

**色源 = 当前活图的 group.color**（"画布 bundle 框的颜色"）。

实现：
1. **改 `graphBlocks(graph)`**：group 块输出增加 `color` 字段（取 `g.color`，缺省 `undefined`）。纯增量，不影响提交上报（Python 若丢弃无害、若透传则新数据自包含）。
2. **新增 `historyLiveBlockColors()`**：对活图跑 `graphBlocks(app.graph.toJSON())`，返回 `Map<blockName, color>`（只取 `source === "group"` 的）。命名口径与渲染内条完全同源（都是 graphBlocks）。
3. 渲染内条时：`const c = liveColors.get(barName) || "rgba(255,255,255,.16)"`。

**已核实**：用户当前活图 group 带 color（快照实测 `#3f789e` / `#b58b2a` / `#a1309b` / `#444`），活图 `_groups[i].color` 同源；历史 entry.blocks[].name 与活图框名一致（"1. Models" 等），能对上。

## 三、五处改动规格

### ① 树高度自适应 + 上限
- 现状：`.htr-panel{height:200px}` + `.tcanvas{height:176px}` 固定 → 行数少时也占 200px，显得高。
- 改：`tcanvas` 高度 = `H`（内容高 `rows*laneH+6`，rows≤4 → ≤166px）；`panel` 高度 auto（随内容）。
- 上限：`H` clamp 到 `[46, 176]`（1 行≈46、4 行≈166；再兜 176 上限）。
- 落点：`historyTreeRenderTree` 里设 `historyTreeCanvasEl.style.height = Hpx`；`.htr-panel` CSS `height:auto`（去掉固定 200）。

### ② 树节点单击看预览 + 双击回跳
- 现状：`node.click → historyTreePick`（回跳）；`mouseenter → bubble`。
- 改：单击 → 显示缩略图浮层（复用 `historyFillThumb`，数据源 `ent.images`）；双击（`HISTORY_TICK_DBL_MS` 内二击）→ `historyTreePick`（回跳）。
- 新增树内浮层容器 `.htr-shots`（照 `#hana-history-bar .hhb-shots` 结构：`.htr-shots-body` + thumb）。挂 `historyTreeEl` 内，绝对定位在节点上方（或面板底部）。
- 消歧：复用框弹层的「单/双击消歧」模式（单击定时器，超时判单击）。

### ③ 框预览铺满宽度 + 滚轮横滚
- 现状：`.hhb-shots-body{display:flex;gap:4px;overflow-x:auto}`，thumb 固定 58×58。
- 改：**单图铺满**框宽（图 `width:100%; height:auto`，圆角保留）；**多图**横向滚动 + 滚轮横滚（照 `.hhb-axis` 的 wheel 处理）。
- 容器：`.hhb-shots-body` 或新 `.hhb-shots-strip` 吃满 `.hhb-shots` 宽（`width:100%`）。

### ④ 框刻度 → 外框+内条
- 现状 `.hhb-tick`：渐变胶囊（色相分谁、save 空心）。
- 改：套用统一母题（外框 border-style/border-color + 内条堆=框色）。宽度变量 `--hhb-tw` 保留（外框总宽）；内条宽 = 100%（受外框 padding）。
- 命中当前框：内条加亮；未命中：保留框色但降饱和（或直接全亮，见拍板"保留加亮"→ 命中亮、非命中常态）。
- `×N` 合并徽标、HEAD 金点、save 语义 → 迁移到新结构。

### ⑤ 树节点 → 外框+内条
- 现状 `.node`：`.htr-bars`（色条堆，命中亮/未命中灰）+ `.htr-stem`（竖线表 kind）。
- 改：套用统一母题（外框 border-style/border-color + 内条堆=框色）。`stem` 的 kind 语义并入外框线型（solid/dashed），可去 stem 或保留极短。
- HEAD 金点、`×N`、legacy 淡化 → 保留。
