## 1. 三态交互各自怎么实现、消歧怎么做

### 1.1 悬停 → 气泡（时间 + 变更节点名）
- `historyBarTickMake` 给每根刻度挂 `mouseenter → historyBarBubbleShow(tick, ent)` / `mouseleave → historyBarBubbleHide()`。
- 气泡内容：第一行 `#NNN · <historyFmtTime(at)>`，第二行为**变更名列表**，由 `historyTickChangedNames(ent)` 产出。
- `historyTickChangedNames` 取值链（严格按契约）：
  1. 主路径 `ent.delta.changed[].title`（P5a 字段，去重后非空即返回）；
  2. 退化：`delta.added[].title` / `delta.removed[].title`；`delta` 存在但三类皆空 → `["无节点变更"]`；
  3. `delta` **缺失/为 null**（P5b 打通前恒为此态）→ 退化为该提交触及的**块名**（`ent.blocks[].title || name`，P5a 完整版块表）；
  4. 仍取不到 → `"#NNN"`（编号）。
- 定位：气泡 `position:absolute` 挂在弹层内（弹层 `#hana-history-bar` 未设 position → static，`.hhb-bubble` 的绝对定位相对**最近定位祖先**；因弹层挂在 `body`，此处以 `getBoundingClientRect` 差值 `tr - br` 计算相对弹层左上角的偏移，避免受祖先影响）。默认锚在刻度**上方**（`tr.top - bh - 6`）；若越出视口上沿则翻到刻度**下方**。水平在弹层宽度内钳制（`0 … barW - bubbleW`）。
- `.hhb-bubble { pointer-events:none }` → 气泡自身不吃鼠标，不打断刻度 hover。

### 1.2 单击 → 缩略图浮层（移开自动关）
- 单击（消歧窗口后才执行）→ `historyTickSelect`（选中）+ `historyBarShotsToggle(tick, ent, ctx)`。
- `historyBarShotsToggle` 把弹层内预留的 `.hhb-shots` 容器 `classList.add("hhb-shots-on")`（默认 `display:none`）；在 `.hhb-shots-body`（`overflow-x:auto`，多图横向滚动）里放一个 `.hhb-thumb` 占位，然后**复用现有 `historyFillThumb(historyBarRequestId, thumb, promptId)`** 渲染（内含 `historyImagesFor` 取图 + 点图开 `historyOpenLightbox` 原图）。无 `promptId` → 显示「这次提交没有关联出图」。
- **移开自动关**：弹层根 `bar` 挂 `mouseleave → historyBarShotsHideSoon()`（180ms 延迟关），`mouseenter → 取消关闭`。→ **浮层本身 hover 时不关，移出弹层才算**。延迟窗口覆盖「刻度 → 浮层」的鼠标穿越。

### 1.3 双击 → 确认框「回到 #NNN 这一刻？」
- 双击（消歧判定）→ `historyTickSelect`（模拟选中，写 `historyBarSelection = {file, seq}` 并高亮刻度）+ `historyBarShotsHide()` + `historyRollbackConfirmOpen(tick, ent)`。
- 确认框 `#hana-history-bar-confirm`（新 id，样式 `#hana-history-bar-confirm`，深色同族，`z-index:10003`）：文案「回到 #NNN 这一刻？」，`[取消]` / `[回跳]`。
- `[回跳]` → 关确认框 + `void historyRollbackExecute()` —— **复用现有 P3-G1 回跳执行路径**（选中态由 `historyTickSelect` 预先设好，`historyRollbackExecute` 直接读 `historyBarSelection`）。`historyRollbackExecute` / `historyRollbackClick` 本体**未改**。
- 确认框锚在刻度下方；越界翻到上方；水平钳在视口内。点空白/重开弹层/收起弹层都会 `historyRollbackConfirmClose()`（经 `historyTickStateClear`）。

### 1.4 单击/双击消歧（240ms）
- 常量 `HISTORY_TICK_DBL_MS = 240`。
- 入口 `historyBarTickClick(ev, tick, ent, ctx)`，用**唯一一个定时器** `historyTickClickTimer` 表示「已收到第一次单击」：
  - 定时器为空 → 起 `setTimeout(240ms)`；到点：清定时器、`historyTickSelect`、`historyBarShotsToggle`（**单击**语义）。
  - 定时器非空（240ms 内第二次点击）→ `clearTimeout` + 清空 → 判为**双击**：`historyTickSelect` + `historyBarShotsHide` + `historyRollbackConfirmOpen`。
- 同一 tick 连点两次自然成立；跨 tick 连点两次也会被同一全局定时器判为双击（沿用「现有 P3 demo 卡就是这个逻辑」的口径：全局单定时器）。

### 1.5 色相 × 形态（2×2，按契约实现，数据有待 P5b）
- 色相分「谁」：`historyTickColor(source)`，`source === "agent"` → `#b189e0`（暖紫）；否则（user/unknown）→ `#5aa0d8`（冷蓝）。写成内联 CSS 变量 `--hhb-c`（不新增样式规则）。
- 形态分「跑/存」：`kind === "save"` → `.hhb-tick[data-kind="save"] { background:transparent; border:2px solid var(--hhb-c) }`（**空心环**）；否则（run/缺省）→ 实心 `background:var(--hhb-c)`。
- 选中态：`.hhb-tick-sel { box-shadow:0 0 0 2px rgba(255,255,255,.9) }`。
