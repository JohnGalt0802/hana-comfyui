# 方案 · 提交树预览浮层叠在气泡上方（2026-10-14 修正）

> **需求**（John 2026-10-14，修正上一版）：点击节点后，**预览图应出现在气泡上方**，而不是让气泡消失。即两者**叠放**：从下到上 = 节点 → 气泡（信息）→ 预览图。
>
> **上一版做错了**：改成"浮层展开时气泡让位（隐藏）"。用户要的是保留气泡、浮层上移叠放。

---

## 1. 现状定位

树里两个浮层都 append 到 `historyTreeEl`（root，`position:absolute`），坐标系一致（相对 root 的 rect）：

| 浮层 | 类 | z-index | 定位（当前） |
|---|---|---|---|
| hover 气泡 | `.htr-bubble` | 5 | `top = 节点顶 - 自身高 - 6`（节点上方） |
| 缩略图浮层 | `.htr-shots` | 6 | `top = 节点顶 - 自身高 - 8`（节点上方） |

两者**都从"节点顶"往上排** → 同位重叠（截图里的"打架"）。

---

## 2. 改动（桥 js，四处）

### 2.1 撤销上一版的"让位"（2 处）

- `historyTreeBubbleShow`：**删** `if (historyTreeShotsTick) return;`（气泡恢复正常显示）。
- `historyTreeShotsToggle`：**删** `historyTreeBubbleHide();`（展开浮层不再收起气泡）。

### 2.2 浮层定位改为"叠在气泡上方"

`historyTreeShotsToggle` 的定位段（当前约 L5548-5561）：
```js
const hr = host.getBoundingClientRect();
const tr = tick.getBoundingClientRect();
const bw = box.offsetWidth;
const bh = box.offsetHeight;
let left = tr.left + tr.width / 2 - hr.left - bw / 2;
left = Math.max(6, Math.min(left, (hr.width || bw) - bw - 6));
const top = tr.top - hr.top - bh - 8;
box.style.left = Math.round(left) + "px";
box.style.top = Math.round(top) + "px";
```
改为：**若有气泡在场，浮层顶 = 气泡顶 - 浮层高 - 间距**（叠在气泡上方）；无气泡则回退为叠在节点上方：
```js
const hr = host.getBoundingClientRect();
const tr = tick.getBoundingClientRect();
const bw = box.offsetWidth;
const bh = box.offsetHeight;
let left = tr.left + tr.width / 2 - hr.left - bw / 2;
left = Math.max(6, Math.min(left, (hr.width || bw) - bw - 6));
// 2026-10-14：浮层叠在气泡上方（气泡在场时）；无气泡则叠在节点上方。
const bub = historyTreeEl.querySelector(".htr-bubble");
let top;
if (bub) {
  const br = bub.getBoundingClientRect();
  top = br.top - hr.top - bh - 6; // 气泡上方
} else {
  top = tr.top - hr.top - bh - 8; // 无气泡：节点上方（原行为）
}
box.style.left = Math.round(left) + "px";
box.style.top = Math.round(top) + "px";
```

**时序保证**：单击时鼠标在节点上 → `mouseenter` 已触发气泡显示 → 浮层 append 时气泡必在场。（若用户点完立刻移开鼠标，浮层位置已在 append 时定好、不再变；气泡消失不影响已定位的浮层。）

### 2.3 保证气泡先于浮层存在（可选加固）

`historyTreeNodeClick` 的单击分支里，在 `historyTreeShotsToggle` 前确保气泡显示（若尚未显示）：

## 4. 验收标准

1. 树里**单击**带图节点 → **气泡照常显示**（`#NNN · 时间` + 变更名），**预览图叠在气泡上方**，两者不重叠。
2. 鼠标移开节点 → 气泡消失，**预览图仍留在原位**（不跟着消失）。
3. **双击**节点 → 回跳确认框（不回归）。
4. hover 节点（不点击）→ 只有气泡，无浮层。
5. 横轴弹层视图不变。

## 5. 成色与风险

- 静态推导（两浮层同坐标系、定位段已读代码坐实），未真机复现。
