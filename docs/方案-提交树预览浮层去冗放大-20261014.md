# 方案 · 提交树预览浮层：去冗、放大、消除与气泡重叠（2026-10-14）

> **需求**（John 2026-10-14，附截图）：提交树里「预览图」和「文字信息」打架；把气泡里的 `run / user` 文字去掉（没意义）；预览图放大（太小）。

---

## 1. 现象与根因

树里**单击**节点 → 出**缩略图浮层**（`.htr-shots`，定位在节点**上方**）；此时鼠标仍悬停在节点上 → **hover 气泡**（`.htr-bubble`）也在，**同样定位在节点上方**。两者都从"节点顶 - 自身高"往上排，必然重叠 → 视觉"打架"。

另：气泡第二行是 `kind / source · 变更节点名`（如 `run / user · RandomNoise…`），其中 `kind/source` 段（run/user）对用户无信息量。

---

## 2. 改动（均在桥 js，三处）

### 2.1 气泡去掉 `kind / source` 段

`historyTreeBubbleShow(tick, ent)`（约 L5417 附近），当前：
```js
const names = document.createElement("div");
names.textContent =
  String((ent && ent.kind) || "run") + " / " + String((ent && ent.source) || "unknown") +
  " · " + historyTickChangedNames(ent).join("、");
b.append(t, names);
```
改为：**只留变更节点名**（去掉 `kind / source` 前缀）；变更名为空时不追加该行：
```js
const changed = historyTickChangedNames(ent).join("、");
if (changed) {
  const names = document.createElement("div");
  names.textContent = changed;
  b.append(t, names);
} else {
  b.append(t);
}
```
（`historyTickChangedNames` 本身不动——横轴弹层气泡仍在用它。）

### 2.2 预览图放大（树浮层 CSS）

当前（`historyTreeStyleEnsure` 内，约 L5000-5025）：
- `.htr-shots { max-width: min(560px, 88vw); }`
- `.htr-shots-img.single { max-width: 520px; max-height: 220px; }`
- `.htr-shots-img.multi { height: 58px; }`

改为：
- `.htr-shots { max-width: min(760px, 92vw); }`
- `.htr-shots-img.single { max-width: 720px; max-height: 340px; }`
- `.htr-shots-img.multi { height: 84px; }`

（图按 `object-fit: contain` 自适应，放大上限即生效。**只改树浮层，横轴弹层 `.hhb-*` 同类样式不动**——本次限定提交树。）

### 2.3 消除重叠：浮层展开时气泡让位

根因是两个浮层同位。修法：**缩略图浮层显示期间，hover 气泡不显示**（单击展开预览 = 进入"看图"态，气泡冗余）。

- `historyTreeShotsToggle(tick, ent)`：在 `host.appendChild(box)` 之后（浮层已显示）调用 `historyTreeBubbleHide()`，即展开浮层立刻收起气泡。
- `historyTreeBubbleShow(tick, ent)`：开头加守卫——若缩略图浮层正开着（`historyTreeShotsTick` 非空）则直接 `return`，不显示气泡。

效果：单击节点 → 浮层出现、气泡消失；移开鼠标再 hover 回来时，只要浮层还开着就不重复弹气泡；关掉浮层（再点同节点/点别的节点/点空白）后，hover 气泡恢复正常。

**不改**：`historyTreeNodeClick` 的单击/双击消歧；`historyTreeShotsHide` 的既有清理；横轴 `historyBarBubbleShow`（弹层内气泡与弹层内浮层本就分列，无此问题）。

## 5. 验收标准

1. 树里**单击**节点 → 出缩略图浮层，**图明显更大**，且**不再有气泡压在上面**（两者不重叠）。
2. 鼠标移开再 hover 回来（浮层仍开）→ 不重复弹气泡；关掉浮层后 hover → 气泡正常显示，且**只显示"#NNN · 时间"+"变更节点名"**（无 `run / user`）。
3. **双击**节点 → 回跳确认框（上一轮的修复不回归）。
4. 横轴弹层视图行为**不变**。
